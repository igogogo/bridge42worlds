# Спринт 2 — исследовательский бот и широкая наука

Составлено 2026-07-29 по решению владельца. Прошлый спринт закрыт: см. `ВЫПУСК-ПРОВЕРКА.md`
(осталась приёмка QA и публикация).

## Цели спринта, по важности

1. **Бот для научных исследований.** Вектор уже построен — теперь собрать вокруг него
   полный контур: вход → вопрос → поиск по смыслу → ответ со ссылками на наши статьи.
   Открывается ТОЛЬКО за авторизацией с лимитами.
2. **Французский язык** — пятый язык сайта.
3. **Ежедневная генерация через API** — конвейер снова живой, каждый день сам.
4. **Вся наука, не только астрофизика** — расширяем периметр разделов arXiv
   пропорционально: биомед, инженерия, информатика и далее. Словари тегов
   обогащаются под новые домены.

## Кто что несёт

| Роль | Главное в спринте |
|---|---|
| DevOps | авторизация+лимиты (достроить), контур бота `/api/ask` |
| ML-инженер | качество бота: как ищем, как отвечаем, как меряем |
| Ведущая сессия | французский, ежедневная генерация, периметр разделов |
| Промпт-инженер | теги для новых доменов, стиль для «не-физики» |
| Обучение | связи новых доменов с курсом; темы 16–17 |
| Разработчик | интерфейс бота на сайте; поиск из ТЗ |
| Дизайнер | вид диалога бота; карточки новых доменов |
| QA | приёмка выпуска 1 (сейчас), потом контур бота |

## Порядок зависимостей

```
авторизация (DevOps)  ──►  /api/ask (DevOps+ML)  ──►  интерфейс (разработчик+дизайнер)
французский (ведущая) ──►  переводы справочников ──►  пересборка
периметр (ведущая)    ──►  теги доменов (промпт)  ──►  ежедневная генерация
```

Подробности — в файле каждой роли.
