# Спринт 2 — план для владельца

Составлено 2026-07-30, после выпуска №1. Горизонт — неделя (до ~06.08).
Цели спринта — в `СПРИНТ-2.md`; здесь — кто, что, и что предъявим в конце.

## Картина одним абзацем

Спринт собирает исследовательского бота на нашем векторе — за авторизацией и лимитами,
с ответами только со ссылками на наши статьи. Параллельно: пятый язык (французский),
конвейер на ежедневном автомате, периметр расширяется со «только астрофизика» на всю
науку с доменными тегами, и цена статьи снижается вдвое по результатам замера.

## Кто что делает и что сдаёт

| Роль | Делает | Результат к концу спринта |
|---|---|---|
| **DevOps** | вход по коду + счётчики лимитов в KV; контур `/api/ask`; суточная сводка в Telegram (трафик CF + наши счётчики + Search Console) | бот отвечает за токеном; читатель видит остаток лимита; тебе каждый день приходит одна строка со статистикой и отдельный сигнал при всплеске |
| **ML** | схема ответа бота, параметры поиска, мерка качества (набор вопросов + число до/после); корпусный граф по ТЗ-ГРАФ | число «доля верных ответов бота»; список первых «непройденных мостов» — кандидатов на точки открытия |
| **Разработчик** | единый поиск по ТЗ-ПОИСК (статика); интерфейс бота: диалог, ссылки-карточки, остаток лимита; учёт расходов на прогон | поиск по всем видам сущностей на 4 языках; диалог с ботом с телефона; после `run.py daily` видна цена прогона |
| **Дизайнер** | вид диалога бота (с разработчиком); решение по карточкам доменов; хвосты: 10 пунктов «после» от продукта | диалог в брендстиле на 375; лента из 20 статей разных наук читается не теряясь |
| **Промпт-инженер** | ретраи переводов → попадание с первого раза; доменные словари тегов; стиль на первых био/инж-статьях; проверка fr в валидации | доля ретраев упала (число в отчёте); у каждого нового домена своё облако тегов |
| **Обучение** | добор кириллицы в главах учебника (хвост блокера 2); связи курса с новыми доменами не тащат мусор; курс скрывает fr до готовности | учебник термодинамики чист на 4 языках; тема 16 «Космология» начата |
| **Контент-менеджер** | читает свежие партии статей по трём осям; приёмка первых не-физических статей; сравнение шлифовки до/после на пробной партии | вердикты по партиям; решение «включаем ли шлифовку» на цифрах |
| **QA** | приёмка выпусков по таблице; регрессии после каждого фикса; живой прогляд «Аналитики» (её никто не смотрел глазами) | таблица выпуска №2 пройдена; чек-лист регрессий актуален |
| **Продукт** | доли доменов в ленте (числа!); дневной лимит бота (число!); рамка приёма сторонних публикаций; стратегия языков после fr | три решения числами, без которых остальные стоят |
| **Ведущая** | замер цены статьи → оптимизация вдвое; французский (add-lang → справочники → пересборка); ежедневный `daily` на автомате; слияния и выпуски | цена статьи с разбивкой и план −50%; сайт на 5 языках; лента пополняется сама каждый день |

## Контрольные точки для тебя

| Когда | Что увидишь |
|---|---|
| День 1–2 | замер цены статьи (число по частям); ежедневный daily на автомате; учебник дочищен |
| Середина | вход+лимиты работают; поиск-статика в деле; французские справочники переведены |
| Конец | **бот отвечает со ссылками на живом сайте** — главная демонстрация спринта; сайт на 5 языках; сводка в Telegram ежедневно |

## Риски, честно

- **Бот** — самая связанная цепочка (DevOps → ML → разработчик+дизайнер): если вход
  и лимиты забуксуют, всё после сдвинется. Смотреть на доску: строка DevOps «взял»
  без «готово» дольше трёх дней — сигнал вмешаться.
- **Французский** — механика готова, но переводы справочников это деньги (~в объёме
  одного дня генерации). Запускаю в дешёвое окно, после замера цены.
- **Вся наука** — ждёт чисел от продукта (доли доменов). Без них не стартует, и это
  правильно: «пропорционально» без пропорций не бывает.

## Что сознательно НЕ в этом спринте

Дообучение своей модели (спор зафиксирован у ML, решаем по числам позже), миграция
индексов в БД (сначала расчёт экономики), сервис сторонних публикаций (ждёт рамку
продукта), Джира (доске две недели испытательного срока).
