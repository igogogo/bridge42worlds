## 2. Связать оставшиеся уроки с сайтом

Из 42 параграфов десять без привязки к нашим тегам, законам и статьям — абстрактные темы
вроде «языка физики», где автоподбор по словарю не сработал.

Инструмент: `python course_link.py` (без модели, по словарю). Для этих десяти нужен ручной
подбор.

**Зачем.** Связки — это то, чем курс отличается от учебника: из параграфа видно живые статьи
по теме.

**Готово, когда:** у каждого параграфа есть хотя бы тег и закон, и хотя бы один пример
из наших статей.

## 2. Расширение курса

Документ: `content-manager/ТЗ-курс-расширение.md`.

и проверка знаний, материалы связаны с сайтом.
