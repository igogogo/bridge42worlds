# Отчёты о работе

По файлу на роль, как и задачи. Сюда пишет исполнитель, отсюда читает ведущая сессия —
это единственное место, где видно состояние всей команды сразу.

## Формат

Новая запись **сверху**, чтобы свежее было видно без прокрутки:

```
## 2026-07-29 · короткая суть

**Сделал.** Что именно, по пунктам.
**Причина.** Если чинил баг — в чём была причина, а не только симптом.
**Не сделал.** Что осталось и почему: не успел, заблокирован, оказалось не нужно.
**Нашёл по дороге.** Чужие задачи, странности, риски. Строкой на каждую.
**Ветка.** Имя ветки и последний коммит.
```

Пять строк, не отчёт на страницу. Из них главные две: **причина** и **нашёл по дороге** —
остальное видно из git.

## Почему не только коммиты

Коммиты показывают, что изменилось. Отчёт показывает, что **не** изменилось и почему —
это то, чего в git не бывает, а решения принимаются именно по этому.
