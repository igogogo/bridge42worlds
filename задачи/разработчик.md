## 1. Тестирование (первым)

Задание: [ТЗ-ТЕСТИРОВАНИЕ.md](../%D0%A2%D0%97-%D0%A2%D0%95%D0%A1%D0%A2%D0%98%D0%A0%D0%9E%D0%92%D0%90%D0%9D%D0%98%D0%95.md).

Пройти сайт руками, собрать список находок. Код пока не править — сначала нужен масштаб.
Особое внимание: уровни чтения, четыре языка, мобильная версия.

**Готово, когда:** есть список находок в формате «где · что · чего ожидал · проверял ли
жёстким обновлением».

## 2. Единый поиск по сайту

Задание: [ТЗ-ПОИСК.md](../%D0%A2%D0%97-%D0%9F%D0%9E%D0%98%D0%A1%D0%9A.md).

Сейчас поле на карточке закона ищет по всем статьям сайта и выглядит сломанным. Делаем один
поиск, который знает, где стоит, и выдаёт результат по видам: статьи, понятия, законы, учёные.

Начинать со статики — лёгкий индекс и фильтрация в браузере. Полнотекстовый поиск на D1 —
следующий шаг, когда станет понятно, чего людям не хватает.

**Готово, когда:** выполнен список в конце ТЗ.

---

## 3. Открытые вопросы интерфейса

Разбирать после находок тестирования, чтобы не делать дважды. Приоритет назначит продукт.

- Единая кнопка глобального поиска в шапке
- Граф знаний — открывать в полупрозрачном полноэкранном режиме по умолчанию
- Архив — календарь по месяцам со счётчиком статей за день
- Переключатель «экспресс» в шапке
- Выровнять правый кластер шапки: уровень, избранное, поиск, календарь, экспресс
