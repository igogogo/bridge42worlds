# Памятка: добавление языка на сайт

Написана 2026-07-30 по горячим следам французского (пятый язык). Цель — чтобы шестой
и десятый язык добавлялись за вечер и без граблей, на которые наступили сейчас.

Держать в паре с решением владельца: **статьи архива — по запросу; учебный раздел,
справочники и интерфейс — полностью.**

---

## Чек-лист, по порядку

**1. Конфиг и структура**
- [ ] `config.json → languages` + новый код. НЕ через `run.py lang add` — он тащит
      перевод всего архива статей, это против решения «по запросу»
- [ ] Проверить `LANG_NAMES` в gen_llm.py (полное имя языка для промптов)
- [ ] `CULTURE_NOTES` в gen_llm.py — культурная заметка переводчику ОБЯЗАТЕЛЬНА:
      аудитория, терминология, правило аналогий, запреты (алкоголь — всегда)
- [ ] RTL? — если да, отдельный проход по вёрстке (опыт арабского: зеркалится не всё,
      знак поправки margin-inline-start, ширина подписей)

**2. Справочники и данные** (~$15–20 на pro, дешевле на flash)
- [ ] `reference_translate.py <код>` — теги, законы, учёные
- [ ] Учебный раздел ЦЕЛИКОМ: курс (course_translate + fr в ROOTS), лекции,
      frontier/discoveries/reference/mathkit/hypotheses (батчами flash)
- [ ] Таксономия arXiv: `data/arxiv-categories-<код>.json` + descriptions
      (иначе 404 в консоли на каждой странице — грабля английского)

**3. Словари интерфейса — главное гнездо граблей.** Аудит одной командой:
`python tools/i18n_audit.py <код>` (если нет — скрипт из отчёта ведущего 30.07:
ищет словари с ru+en без нового кода). Места, где словари живут:
- [ ] generate.py — ~70 словарей локализации страниц
- [ ] js/search.js (UI_STRINGS, SORT_LABELS, CAL_LABELS...), js/scroll.js,
      js/analytics.js, js/likes.js
- [ ] js/course-i18n.js, js/figures-i18n.js (148 подписей схем), js/tutor.js
- [ ] Заглушка «статья не переведена» (untranslated_stub) — на новом языке
- [ ] Плашка «версия уровня не готова» — С ДИАКРИТИКОЙ (испанская грабля:
      «Anadelo» вместо «Añádelo» жила на 2968 страницах)
Способ: только батчем через flash, не руками. Валидатор ловит кириллицу
в новом языке автоматически (target != ru).

**4. Сценарий «молодого языка»** — читатель не должен увидеть скелет:
- [ ] Плашка на тонкой ленте (<20 статей): «раздел открылся, N статей, растёт
      ежедневно» + ссылки на полные справочники и курс
- [ ] sitemap нового языка — только переведённые страницы (не скармливать
      поисковику заглушки)
- [ ] feed-<код>.xml создаётся и валиден пустым
- [ ] about: карточка языков + словарь about на новом языке

**5. Включение и приёмка**
- [ ] Полная пересборка (создаст страницы языка) — из main, ведущая
- [ ] Быстрый QA «путь читателя нового языка»: главная → плашка → статья →
      честная заглушка → справочник → курс → поиск → 375px → (RTL?)
- [ ] Проверить консоль на 404 (таксономия, картинки)
- [ ] about и ВЫПУСК-ПРОВЕРКА обновлены
- [ ] Публикация. Язык виден в переключателе только с этого момента —
      до выпуска он «тёмный»

**6. После выпуска**
- [ ] Новые статьи идут с языком автоматически (конвейер читает config)
- [ ] ВАЖНО: процессы, запущенные до включения языка, держат старый config
      в памяти — их статьи выйдут без нового языка (грабля fr: прогон 24–29)
- [ ] Перевод архива — по запросу читателя (очередь), не батчем
- [ ] Строка расхода: перевод статьи на язык ≈ $0.01 (flash+дедуп), учебный
      раздел целиком ≈ $8–15
