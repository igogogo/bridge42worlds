# Что мы строим и кто за что отвечает

Один рисунок целиком: чтобы каждый видел свою часть и **не лез в чужую**. Пересечения дороже
простоя — два человека, правящие один файл, тратят третий день на разбор конфликта.

---

## Замысел в одном абзаце

Мы берём свежие научные работы с arXiv и превращаем их в тексты, понятные человеку без
подготовки, — сразу на пяти языках. Не пересказ ради пересказа: читатель должен понять, что
было неясно до этой работы, что стало ясно после, каким приёмом это добыто и есть ли от
этого польза уже сегодня. Проект некоммерческий и остаётся таким: доступ не продаём, рекламу
не показываем, вниманием не торгуем.

---

## Из чего состоит система

```
   arXiv ──┬── живой API ──────► ежедневная лента (за позавчера)
           └── локальный дамп ─► история, дыры покрытия, ретроспектива
                                          │
                                          ▼
                            ОТБОР: что достойно разбора
                                          │
                                          ▼
                     ГЕНЕРАЦИЯ: экспресс (из аннотации)
                                 полная (из PDF, каскад уровней)
                                          │
                                          ▼
                      ПЕРЕВОД на пять языков + контроль качества
                                          │
                                          ▼
                   СМЫСЛОВОЙ СЛОЙ: теги, законы, учёные, связи статей
                                          │
                                          ▼
                          САЙТ: 42 471 страница, лента, поиск,
                                граф знаний, аналитика, обучение
                                          │
                                          ▼
                     ЧИТАТЕЛЬ ──► НАБЛЮДАТЕЛЬНЫЙ СОВЕТ ──► решения
```

Замыкающая стрелка — главная: читатели, дочитавшие до совета, определяют, куда проекту
двигаться. Это не витрина обратной связи, а механизм управления.

---

## Кто чем владеет

Владение означает: **правишь только ты, остальные пишут тебе**.

| Роль | Владеет | Не трогает |
|---|---|---|
| **Архитектор** (ведущая сессия) | слияния, выкатка на прод, `generate.py`, шаблоны, CSS, интерфейс, целостность данных | чужие ветки без слияния |
| **ML** | вектор, эмбеддинги, привязка по смыслу, граф статей, отбор, дыры покрытия, `data/embeddings-*`, `related-vec.json` | шаблоны, CSS, промпты генерации |
| **Промпты** | всё в `data/prompts/`, качество текста, языковые требования, мерки текста | код генератора, интерфейс, вектор |
| **DevOps** | `cloudflare/`, Worker, R2, кэш, квоты, планировщик, секреты | контент, промпты, интерфейс |
| **Стратег / секретарь** | совет, регламент, повестка, резюме решений, замысел новых направлений | код целиком — предлагает, не правит |
| **Дизайнер** | дизайн-система, типографика (сейчас на паузе) | всё остальное |
| **QA** | приёмка по маршрутам, блокеры | правки — только в отчёт |

## Границы, где мы уже сталкивались

1. **Промпты живут в `data/prompts/`.** Папка `content-manager/prompts/` — мёртвая копия;
   архитектор правил её и отчитался о работе, которой не было. Промпт-инженер сводит их
   в одну — до этого момента правит ТОЛЬКО он.
2. **Теги уходят из промпта в вектор.** Пока ML не отдал измеренную привязку, промпт-инженер
   не выбрасывает блок тегов, а архитектор не переключает ленту. Порядок: ML измерил →
   владелец посмотрел → архитектор переключил.
3. **Интерфейс правит архитектор.** Дизайнер на паузе не потому, что плохо работает, а
   потому что система только что выровнена и любой сдвиг сейчас дороже пользы.
4. **Публикует только ведущая сессия.** У всех остальных `B42_NO_PUBLISH=1`.
5. **Два прогона на одном дереве — гонка.** Перед платным прогоном смотри `git log` и
   `git status`: не работает ли кто-то ещё.

## Что каждый отдаёт остальным

- **ML → всем**: `tags_vec` (теги по смыслу), `related-vec.json` (связи статей), списки дыр
  покрытия с идентификаторами — готовые к генерации.
- **Промпты → генерации**: файлы в `data/prompts/`, ничего больше.
- **DevOps → всем**: работающий прод, ключи, квоты, планировщик.
- **Стратег → владельцу и совету**: повестка, резюме, отчёт о выполнении.
- **Архитектор → всем**: слитый main, статус проекта, ответы на вопросы из отчётов.

---

## Чем меряем работу

Не строками кода и не количеством правок, а тем, изменилось ли **число**:

- статей в ленте и языков у них;
- доля тегов, у которых есть статьи (было: половина словаря мертва);
- доля статей со связями по смыслу (сейчас 88%);
- себестоимость статьи (сейчас цент с переводом на пять языков);
- сбоев перевода, потерянных маркеров, битых страниц;
- участников совета и внесённых предложений.

Работа без изменения числа — не результат, а деятельность.
