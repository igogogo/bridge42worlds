# Доска — кто что делает прямо сейчас

Один файл на всю команду. **Одна строка на задачу.** Новые строки — сверху таблицы.

Зачем: владелец не должен спрашивать «кто чем занят», а ведущая сессия не должна
ходить по веткам и угадывать. Открыл файл — увидел всё.

## Правило трёх касаний

Каждый касается своей строки **три раза**, по одному слову в колонке «статус»:

1. **взял** — в момент, когда начал. Тогда же вписал имя ветки.
2. **готово** — когда запушил ветку и написал отчёт. НЕ когда «почти».
3. — третье касание не твоё: **слито** ставит ведущая сессия при слиянии.

Больше ничего сюда не пишут: подробности живут в отчёте (`отчёты/<роль>.md`),
обсуждения — в чате. Доска — только состояние.

## Цикл выпуска (правило владельца 2026-07-29)

```
все строки «готово» → слияние → обсудили результаты → QA по таблице выпуска →
полечили финальное → publish
```

Ведущая сессия смотрит на доску; когда у всех «готово» — сама начинает слияние,
никого не спрашивая. Кто не поставил «готово» — тот ещё работает, его не ждут
дольше договорённого.
