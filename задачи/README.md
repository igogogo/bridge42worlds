Отчёты о работе — папка [отчёты/](%D0%BE%D1%82%D1%87%D1%91%D1%82%D1%8B/), тоже по файлу на роль.
Задача говорит, что делать; отчёт — что получилось и что помешало.

## Как этим пользоваться

**Берёшь задачу сверху своего файла** — они отсортированы по важности, не по удобству.

**Формат задачи одинаковый везде:** что сделать, зачем это нужно, и по чему поймём, что готово.
Последнее важнее всего: без него «сделано» у каждого своё.

**Закончил — переносишь строку в «Сделано»** внизу своего файла, одной строкой с датой.
Не удаляешь: через неделю никто не вспомнит, почему решили именно так.

**Нашёл по дороге чужую задачу** — не чини молча, допиши в файл той роли. Молчаливая правка
в чужой зоне ломает чужие планы.

**Раз в несколько дней пиши в свой отчёт** — [отчёты/README.md](%D0%BE%D1%82%D1%87%D1%91%D1%82%D1%8B/README.md).
Пять строк. Главное в них — причина, если чинил баг, и что нашёл по дороге: этого
в коммитах не видно, а решения принимаются именно по этому.

## Правила работы

Ветка на задачу, в ветке только исходники, сборку и публикацию делает ведущая сессия —
[ПРАВИЛА-РАБОТЫ.md](../%D0%9F%D0%A0%D0%90%D0%92%D0%98%D0%9B%D0%90-%D0%A0%D0%90%D0%91%D0%9E%D0%A2%D0%AB.md).

Отдельные папки, чтобы не мешать друг другу:

    git worktree add ../b42-<роль> -b <ветка>
