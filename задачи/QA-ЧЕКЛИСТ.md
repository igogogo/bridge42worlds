## Чем мерить

Панель превью врёт про ширину: рапортует 375, а `innerWidth` остаётся десктопным — на этом
уже завели ложный баг «гамбургер не открывает меню». Мерить только headless-браузером через
CDP, переустанавливая размеры **после** каждой навигации, с выключенным кэшем.

Харнесс сессии: `cdp.py` (класс `Browser`: `visit`, `js`, `shot`, `console`). Держать в
скретчпаде, в репозиторий не класть — он про инструмент, а не про сайт.

Свой порт для сервера. На 8420 у нас регулярно висят серверы других сессий, иногда из чужих
worktree — измеришь чужое дерево и не заметишь.

Перед прогоном проверить: `.build.lock` отсутствует (иначе идёт чужая сборка, дерево
в промежуточном состоянии) и сборка свежее последнего слияния — сравнить mtime `templates/`
и `lang/*/index.html`.

## 1. Языки: ru · en · es · ar

- [ ] Кириллицы нет на en/es/ar — по **видимому** тексту, включая SVG `<text>`/`<tspan>`,
      `alt`, `title`, `aria-label`, `placeholder`. Утечка идёт из шести мест: текст, формулы,
      аннотация, словари подписей, подписи меток на схемах, молчаливые откаты в генераторе
- [ ] Язык держится при переходах: лента → статья → уровень → похожие → тег → закон → учёный →
      раздел → избранное → аналитика → граф → обратно. На каждом шаге `documentElement.lang`
- [ ] Ссылки ведут в свой язык, а не в `ru`. Исключение по умыслу — обложки, они лежат один раз
- [ ] Переключатель языка ведёт на **ту же** страницу другого языка, а не на главную
- [ ] `dir=rtl` на ar везде; на остальных `ltr` и rtl не протекает
- [ ] Корневые страницы (`?lang=xx`) держат язык при переходах и при возврате в собранный сайт
- [ ] Единицы измерения и подписи схем — на языке страницы

## 2. Мобильная: 375 и 320

- [ ] `documentElement.scrollWidth <= innerWidth + 1` — ничего не вылезает за экран
- [ ] Ни один элемент не выходит за края: `rect.right > innerWidth + 1` или `rect.left < -1`.
      В rtl проверять оба края, зеркалится не всё
- [ ] Ничего не теряется: сравнить состав видимых блоков на 1280 и на 375. Спрятанное меню —
      умысел, пропавший блок «похожие» — потеря
- [ ] Контролы не мельче 44 px. Порог только для контролов (`button/input/select`, классы
      `btn|toggle|chip|ctrl|star|fav|burger`), не для ссылок в потоке текста
- [ ] Текст влезает в кнопку: `scrollWidth <= clientWidth`
- [ ] Шапка не переносится, правый кластер одной высоты
- [ ] Соседние контролы не наезжают друг на друга
- [ ] **Печатать реальный `innerWidth`** в доказательстве — без этого находка не принимается

## 3. Ширина шапки = ширина страницы (1280 и 375, ltr и rtl)

- [ ] Левый край меню = левый край текста, правый = правому. Считать числа, разъезд > 4 px —
      находка
- [ ] Ограничения ширины живут в разных местах и расходятся молча: `.top-bar` 620,
      `.langs-row` 680, страница бывает 900+. Ломается почти всегда на **широком** экране
- [ ] Проверять все типы страниц, включая корневые учебные — там разъезд уже был на 248 px

## 4. Целостность и ссылки

- [ ] `run.py links` — битых только из известного списка. Запускать с `SKIP_R2_PUBLISH=1
      SKIP_R2_BACKUP=1`
- [ ] `run.py check` — «недопечённых» папок не прибавилось
- [ ] Ссылки внутри статьи и в связях уроков отвечают 200 — запрашивать, а не проверять
      наличие файла на диске
- [ ] Карта сайта `lang/*/data/about.json` перечисляет все реальные разделы, составы совпадают
      между четырьмя языками

## 5. Связность графа

- [ ] У каждого тега, закона, учёного есть хотя бы одна связь с **другим типом**
- [ ] Рёбер на несуществующие узлы нет
- [ ] Отчёт числами: всего / есть межтип / только свой тип / без связей — по каждому типу
- [ ] Сверить данные с тем, что показано на странице: бывает, связь в данных есть, а блок пуст
- [ ] Отдельно смотреть тег, у которого имя совпадает с именем закона или фамилией учёного:
      если такие не связаны — сломан линковщик, а не пробел в данных

## 6. Поиск

- [ ] Есть на всех общих вкладках: лента, теги, законы, учёные, разделы, архив, избранное
- [ ] Находит по всем видам карточек: статья, тег, закон, учёный, раздел
- [ ] Заведомо отсутствующий запрос даёт внятное «ничего не найдено», а не пустоту молча
- [ ] Работает на ar по арабскому слову, а не по русскому индексу
- [ ] На 375 не ломает шапку и не уезжает за правый край

## 7. Графы и интерактив

- [ ] Узлов > 0 и рёбер > 0 **фактически в DOM**, а не «ошибки нет — значит нарисовалось»
- [ ] Клик по узлу ведёт на живой адрес и в язык страницы
- [ ] Подписи узлов на языке страницы
- [ ] Консоль без ошибок до и после взаимодействия
- [ ] На 375 холст помещается, легенда и управление не наезжают

## 8. Качество статей (выборочно, 15 статей × 4 языка)

- [ ] Текст не обрывается; медиана длины по языкам не расходится в разы
- [ ] Формулы отрендерены (`.katex` в DOM), сырых формул и `ParseError` нет
- [ ] Картинки загрузились (`naturalWidth > 0`), обложка на месте. Ловушка — webp против jpg
- [ ] Нет следов кухни: плейсхолдеры, куски промпта, незакрытые маркеры `[tag..]`, `undefined`,
      `null`, `NaN`
- [ ] Аннотация и ключевые числа на месте и на языке страницы
- [ ] Уровни просмотра: переключатель работает, выбор ведёт себя как задумано, не ведёт в 404,
      не ломает шапку

## 9. Выпуск

- [ ] Публикация — **после** приёмки, не до. Проверить, что после сборки в R2 ничего не уезжало:
      mtime `cloudflare/.r2-manifest.json` старше конца сборки
- [ ] Проверки и сводки не публикуют. Список READONLY в `run.py` и список исключений в
      `cloudflare/deploy_r2.py` — искать пары правил, они расходятся
- [ ] Что уедет в R2, кроме страниц: недопечённые папки статей публикуют обложку и
      `references.txt`, хотя страниц у них нет

## Наши повторяющиеся грабли

Держать в голове при любой проверке. Полное описание — в [qa.md](qa.md).

1. Русский в нерусских версиях — из шести мест сразу
2. Молчаливый откат вместо ошибки: пустой `catch`, значение по умолчанию. Снаружи цело, внутри пусто
3. Одно правило в двух местах обязательно разойдётся — искать пары
4. Смешанные идентификаторы: составной ключ `2606.31362_en_popular` против чистого `2606.31362`
5. Ссылка на язык по умолчанию вместо языка страницы
6. Мобильная: перенос шапки, наезд, кнопки мельче 44 px
7. Кэш — половина «не применилось»
8. Ссылки на несуществующее
9. Шапка шире или уже страницы — ломается тихо и на широком экране
