A.3 Strategies for multi-armed bandits
For standalone action selection of neural targets, we use OPhELIA to augment Bayesian Active
Learning (BAL). We also consider a selection of well-known and widely used solutions to the
multi-armed bandit problem, which we describe below as they are framed in the context of optimal
photostimulation selection of ensembles.
A.3.1 Bayesian Active Learning (BAL)
For the first model that we augment with OPhELIA, we employ a first order approximation of
Bayesian Active Learning by Disagreement (BALD) [ 49], which is a prominent active learning
strategy which is well-suited for selecting informative training set samples for supervised learning
problems [50]. In our case, the goal is, equivalently, to select the next stimulation targeti.
In a BALD formulation for our problem, the optimal query would maximize the expected reduction
in posterior entropy. However, notice that E[H[p(r|i, θ)]] is intractable, since response vector
r∈ {0,1}Nr entails a summation over 2Nr possible outcomes. Instead of the BALD objective term,
we thus consider the posterior variance, and select actions which minimize this term. With OPhELIA,
we refer to our BAL approach as OPh-AL.

A.5 Training a random forest for prior inference
To predict target-level ambiguity from pre-perturbation activity features, we used a
RandomForestRegressor (Scikit-learn) [ 51] with n_estimators=300, max_depth=4,
min_samples_leaf=2. Input features were derived from spontaneous and visually evoked
activity statistics prior to photostimulation experiments. The model was trained to predict mean
responder entropy ¯Hi for each stimulation target i or Ck for combinatorial selection. We weighted
the learned prior contribution using parameter λ= 0.35 . Model performance was evaluated using
leave-one-out cross-validation (LOOCV), and performed separately for each subject.
