Калейдоскоп симметрий: новый рекорд в подсчёте хордальных графов

Original: "Counting Unlabeled Chordal Graphs by Equivariant Evaporation"
· Matthew Sun
arXiv:2607.02613 · 2026-07-01 · CC BY 4.0 · 3 мин
Дискретная математика Комбинаторика
Впервые за десятилетие обновлены две последовательности из OEIS, считающие различные хордальные графы, — благодаря алгоритму, который использует симметрию как увеличительное стекло.
Аннотация

Ранее количество непомеченных хордальных графов — общего (OEIS A048193) и связного (OEIS A048192) — было известно только до n=15. Продление до n=20 выполнено методом Пойи — Бернсайда: число непомеченных графов в классе, замкнутом относительно переименования, равно среднему по S_n от числа помеченных графов, инвариантных к каждой перестановке. Для произвольной перестановки π число π-инвариантных помеченных хордальных графов найдено через динамическое программирование, расширяющее испарительный подсчёт Hebert-Johnson, Lokshtanov и Vigoda на эквивариантный случай. Его центральный элемент — разложение в пучки делителей: связный фрагмент, охватывающий циклическую орбиту длины c, для каждого делителя d числа c образует d-кратный пучок из объектов того же типа в циклическом мире порядка c/d, вычисляемых рекурсивно. Доказана правильность рекуррент и показано, что полный бёрнсайдовский перебор работает за субэкспоненциальное время n^{O(√n)}. Представлены члены последовательностей вплоть до n=20; проведена перекрёстная проверка четырьмя способами, включая совпадение со старыми значениями и тест согласованности методом Эйлера.

Контекст

Многие структуры — от молекул до социальных сетей — удобно описывать графами. Но когда важны не имена вершин, а лишь связи между ними, на первый план выходит перечисление непомеченных объектов. Хордальные графы, лишённые индуцированных циклов длины больше трёх, — один из центральных классов в алгоритмической теории графов. Они моделируют разреженные иерархические сети и лежат в основе эффективных алгоритмов. Несмотря на десятилетия усилий, точное число таких графов было известно лишь до 15 вершин. Дальнейшему продвижению мешала необходимость учесть все возможные симметрии — перестановки, превращающие один рисунок в другой, неотличимый без пометок.

Методы

Центральный инструмент — лемма Бёрнсайда: число непомеченных объектов равно среднему числу помеченных объектов, неподвижных при каждой перестановке из группы симметрий. Для группы всех n! перестановок это сводится к сумме по типам циклов. В 2021 году Хеберт-Джонсон, Локштанов и Вигода предложили эффективный динамический алгоритм для подсчёта помеченных хордальных графов через процесс «испарения»: из графа многократно удаляются симплициальные вершины (чьи соседи образуют клику), пока не останется пустой граф. Новый подход адаптирует это испарение к миру с симметрией, превращая его в орбитное испарение: все вершины одной орбиты испаряются одновременно. Ключевая находка — декомпозиция делительных пучков. Если перестановка содержит цикл длины c, а компонента связности охватывает несколько орбит, то её структура раскладывается в пучок из d компонент, каждая из которых симметрична относительно меньшей группы порядка c/d. Это позволяет сводить расчёт к рекурсивному вызову той же задачи в «подмире» с уменьшенными орбитами. В результате строится система рекуррентных соотношений, вычисляющая точное число инвариантных хордальных графов для каждого типа циклов. Реализация этого вычислительного метода потребовала тщательного программирования и проверки.

Результаты

Опираясь на этот аппарат, автор вычислил обе последовательности — общую и связную — вплоть до n=20. Для n=16 число всех хордальных графов равно 5 985 406 996 403, для n=17 — 247 178 491 630 853, а для n=20 достигает 7 278 601 292 779 396 715. Проверка проводилась четырьмя независимыми способами: полное совпадение с ранее известными членами до n=15; прямое переборное подтверждение для малых типов циклов; воспроизведение помеченного предела; и — отдельно — проверка через преобразование Эйлера, связывающее общие и связные последовательности. Теоретическая оценка доказала, что алгоритм работает за субэкспоненциальное время n^{O(√n)} — гораздо быстрее, чем общий параметризованный подход, требовавший бы однократной экспоненты.

Значение

Эта работа не просто обновляет две строчки в OEIS. Она демонстрирует, что «испарительный» метод совместим с анализом симметрий, и предлагает конструктивную схему для других классов графов, допускающих подобные декомпозиции. Связь между симметрией и инвариантами, столь глубокая в физике, здесь получает комбинаторное воплощение. Декомпозиция делительных пучков, по сути, объясняет, как симметрия высокого порядка собирается из повторяющихся блоков низшей симметрии, — и это может найти применение далеко за пределами хордальных графов, в любых перечислительных задачах с действием циклических групп.

Развитие

Ближайшие перспективы — распространение метода на другие классы графов, например, на интервальные графы или графы сравнимости. Возможно усовершенствование алгоритма для работы с перестановками, имеющими много мелких орбит, которые сейчас отнимают львиную долю времени. Интересно и обратное направление: могут ли физические модели, использующие испарение (например, в статистической механике), извлечь пользу из комбинаторных методов, учитывающих симметрию?

Влияние

Результат окажет влияние на теорию графов, комбинаторику и разработку алгоритмов. В частности, он даёт эталонные данные для тестирования генеративных моделей сетей и для приложений, требующих перебора неизоморфных структур.

Следующие шаги

Следующий шаг — формализация условий, при которых декомпозиция делительных пучков переносится на другие классы, и реализация распределённых вычислений для достижения n=21 или 22.

Ключевые проблемы

Задача перечисления непомеченных структур — это комбинаторный аналог понимания фазового пространства сложных систем. Связь с проблемой изоморфизма графов и с вопросами эффективного учёта симметрий делает эту работу актуальной для фундаментальных проблем теории сложности и для приложений в хемоинформатике, где часто нужно перебирать неизоморфные молекулярные графы.
