APPENDIXA
PRELIMINARIES
Before detailing the proposed architecture, we first review
the foundational concepts and mathematical control frame-
works that underpin the methodology utilized in this paper.
A. Model Predictive Control
MPC [26] is an optimization-based control strategy that
determines control inputs by solving a finite-horizon optimal
control problem at each time step. Given a dynamical model
of the system, MPC predicts the future evolution of the system
states over a receding prediction horizon and computes a
sequence of control inputs that minimize a predefined cost
function while satisfying system dynamics and constraints.
Consider a discrete-time dynamical system

denotes the control input at time stepk. The MPC controller

input of the optimal sequence is applied to the system. The
optimization problem is then resolved at the next time step
using updated state measurements, resulting in a receding
horizon control strategy.
B. Control Barrier Functions
CBFs [27] provide a framework for enforcing safety and
state constraints in dynamical systems by guaranteeing the
forward invariance of a desired safe set. Consider a control-
affine dynamical system of the form
˙x=f(x) +g(x)u,
wherex∈R n is the system state andu∈R m is the control
input.
Let the safe set be defined as

In optimization-based control frameworks, such as MPC, the
CBF condition can be incorporated as an inequality constraint
to ensure that safety or task-related requirements are satisfied
during system evolution.
