A Reproduction Script
The Python scriptvasco_storm_analysis.py, submitted as an ancillary file with this
preprint, reproduces every numerical result in this paper. It requires two publicly avail-
able input files:
1. The supplementary dataset from Bruehl & Villarroel (2025), available at DOI:
10.1038/s41598-025-21620-3.
2. The GFZ Kp archive, available athttps://kp.gfz.de/app/files/Kp_ap_since_
1932.txt.
Dependencies:openpyxl,statsmodels,scipy,numpy.
Run:python vasco_storm_analysis.py
The script executes the following analyses in sequence:
1. Load the Bruehl & Villarroel transient dataset
2. Load the GFZ Kp index and build a daily storm lookup
3. Compute lunar-phase bins and exclude low-observation phases
5
4. Storm suppression test (0–4 day window, two-proportionZ-test)
5. Dose-response across five Kp bins (Cochran–Armitage trend)
6. Nuclear test day geomagnetic conditions (scheduling bias test)
7. Interaction table (nuclear×storm status)
8. Logistic regression with and without Kp control
9. Summary of all results
Every number in the paper can be traced to a specific output line. The complete script
is also archived at osf.io/8ryhk with a pre-analysis timestamp.
