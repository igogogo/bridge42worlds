контрастивное обучение

Обучать, сравнивая похожее и непохожее, — так работает контрастивное обучение. Вместо того чтобы зазубривать имена, нейросеть учится улавливать суть, отличая кошку от собаки, даже если их не называли.

На практике: Распознавание лиц без меток, поиск похожих снимков в больших архивах, улучшение диагнозов по медицинским изображениям, когда мало размеченных данных.
Контрастивное обучение — это подход в машинном обучении, позволяющий строить качественные представления данных без разметки (self-supervised learning). Оно опирается на понятие контрастной потери: модель притягивает представления (embedding) семантически близких объектов (positive pairs) и отталкивает представления несвязанных (negative pairs). Например, для изображений позитивными парами служат разные ракурсы (аугментации) одного и того же снимка, а негативами — любые другие изображения в мини-пакете. Таким образом, нейросеть учится выделять инвариантные признаки, игнорируя несущественные вариации освещения, поворота, масштаба. Метод лёг в основу многих современных систем распознавания, где зачастую превосходит обучение с учителем при малом количестве меток.

История

Идея учиться на сравнениях стара: ещё в 2006 году метод «Siamese networks» использовался для проверки подписей. Но современный бум начался в 2018–2020 годах, когда учёные из Google (SimCLR) и Facebook (MoCo) предложили способы обучать большие нейросети без участия человека, создавая пары из одного изображения с разными искажениями.

Как работает

Берём одно изображение и делаем из него два новых — например, поворачиваем и меняем цвет. Эти два варианта — положительная пара. Другие изображения в наборе — отрицательные. Нейросеть переводит каждое изображение в вектор чисел. Её задача — уменьшить расстояние между векторами положительной пары и увеличить до отрицательных. Со временем векторы начинают хранить смысл картинки, а не случайные детали.

💡 Система CLIP от OpenAI, обученная контрастивно на парах изображение-текст, способна рисовать картины по описанию, хотя её никогда не учили художественному стилю напрямую — она просто уловила взаимосвязи.
Контрастивное обучение — это метод, при котором компьютерную программу (нейросеть) тренируют находить сходства и различия между объектами. Ей показывают пары примеров: одни пары похожи друг на друга (например, две фотографии одного человека), другие — непохожи (фотографии разных людей). Программа старается сделать так, чтобы в своей «памяти» (векторе признаков) похожие объекты оказывались рядом, а непохожие — далеко. Это похоже на игру «найди пару», только для миллионов картинок.

Идея учиться на сравнениях стара: ещё в 2006 году метод «Siamese networks» использовался для проверки подписей. Но современный бум начался в 2018–2020 годах, когда учёные из Google (SimCLR) и Facebook (MoCo) предложили способы обучать большие нейросети без участия человека, создавая пары из одного изображения с разными искажениями.

Со временем векторы начинают хранить смысл картинки, а не случайные детали.

Контрастивное обучение (contrastive learning) — это семейство методов обучения представлений, в котором модель оптимизирует метрическое пространство так, чтобы семантически схожие объекты отображались в близкие точки, а различнные — в далёкие. Формально, для каждого якорного примера x формируется положительный пример x⁺, как правило с помощью аугментаций или контекста, и набор отрицательных примеров {x⁻_i}. Минимизируется потеря, основанная на softmax-сравнении: модель поощряет высокое сходство между x и x⁺ относительно всех остальных пар. Ключевая инновация последних лет — использование больших мини-пакетов и механизмов памяти для хранения отрицательных примеров (MoCo) или отказ от отрицательных пар при помощи асимметричных архитектур (BYOL, SimSiam). Теоретический анализ связывает контрастивное обучение с максимизацией взаимной информации и обучением на положительно-определённых ядрах.

История

Корни уходят в метрическое обучение: сиамские сети (Bromley et al., 1993) для сравнения подписей. В 2006 году Хадселл и Лекун предложили contrastive loss для обучения инвариантных представлений. Возрождение интереса связано с прогрессом в self-supervised learning для изображений: в 2018 году модель InstDisc (Wu et al.) использовала memory bank; прорывными стали MoCo (He et al., 2020) с очередью отрицательных примеров и SimCLR (Chen et al., 2020) с большим размером батча и сильной аугментацией. Эти работы показали, что контрастивное предобучение достигает точности, близкой к обучению с учителем, а иногда и превосходит его при дообучении на малых выборках. Впоследствии подход адаптирован для видео, аудио, графов и многомодальных данных (CLIP, 2021).

Как работает

Алгоритм включает три этапа: (1) стохастическая аугментация данных создаёт два независимых представления одного входа (например, случайное кадрирование, искажение цвета); (2) кодировщик (ResNet, ViT) отображает их в векторы скрытого пространства; (3) проекционная голова (MLP) преобразует их в более низкоразмерное пространство, где вычисляется контрастная потеря InfoNCE: L = -log[ exp(sim(z_i, z_j)/τ) / ∑_{k=1}^{2N} 1_{k≠i} exp(sim(z_i, z_k)/τ) ], где sim — косинусное сходство, τ — температурный параметр. Оптимизация понижает взаимную энтропию между распределением положительных и отрицательных пар. Чтобы избежать коллапса представлений (вырождения всех векторов в одну точку), применяют механизмы: отрицательные пары из очереди (MoCo), стоп-градиент и предсказатель (BYOL), кластеризацию (SwAV). В итоге скрытое пространство приобретает семантическую структуру, инвариантную к заданным преобразованиям.

L_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k=1}^{2N} \mathbf{1}_{k \neq i} \exp(\text{sim}(z_i, z_k) / \tau)}
L_{i,j} — значение потери для пары (i, j); z_i, z_j, z_k — векторы представлений (эмбеддинги) в скрытом пространстве (безразмерные, нормированы); sim — функция сходства, обычно косинусное сходство: sim(z_i, z_j) = z_i^T z_j / (||z_i|| ||z_j||) (безразмерная, от -1 до 1); τ — температурный параметр (положительное число, обычно 0.1–0.5), регулирует остроту распределения; N — размер мини-пакета (количество исходных изображений, после аугментации получаем 2N векторов); 1_{k ≠ i} — индикаторная функция, исключающая пару i=j из знаменателя

Открытые проблемы и интересные факты

Как выбирать аугментации, гарантирующие сохранение семантики, для произвольных типов данных (аудио, графы, видео)?; Почему некоторые методы (BYOL, SimSiam) работают без отрицательных пар, избегая коллапса — полной теоретической ясности нет.; Можно ли распространить контрастивное обучение на задачи с непрерывным выходом (регрессия) или временные ряды без потери качества?; Существует ли универсальный контрастивный претренинг, переносимый на любую downstream-задачу без тонкой настройки?
