Recurrent Neural Networks

A person reads a book and remembers the plot to avoid confusing the characters. A recurrent network works the same way: it takes each new word without forgetting what came before, and predicts what will follow.

In practice: Text autocomplete on a phone, machine translation, smart speaker processing of long phrases.
The conductor's baton hangs in the air—the musician waits, remembering the previous motif. A recurrent network iterates over sequence tokens (characters or words) and after each updates the hidden state (a vector of numbers). This state is a compressed description of everything seen so far. Thanks to the feedback loop, the network can capture dependencies between distant elements: for example, case agreement in a long German sentence.

History

The first recurrent networks were proposed in the 1980s, but those architectures quickly 'forgot' what had happened long before. In 1997, scientists invented LSTM—a special cell that learned to retain important information for a long time; this was a breakthrough for tasks like speech recognition.

How it works

At each step, the network receives a new input and its short-term memory (a vector of numbers describing what the network has remembered). It updates this memory by mixing new information with what it already knew and produces an output. For example, reading 'I love cats,' by the word 'cats' it already remembers that it's about me, not someone else.

💡 LSTM networks, created in 1997, remained the primary tool for machine translation for almost 20 years, until transformers supplanted them—yet they are still used in millions of smartphones for text autocomplete.
An old conductor remembers every note played, even when the orchestra is already playing a new bar. A recurrent neural network (a program that works with sequences) is like that conductor. It reads data step by step (letter by letter or word by word) while keeping a 'brief summary' of everything read in memory. This allows it to finish a phrase or translate a sentence.

The conductor raises the baton. Each note builds on the previous one, holding the melody in memory. A recurrent neural network (RNN) is a class of architectures for processing sequential data where connections between elements can form directed cycles. Unlike feedforward networks, RNNs maintain a hidden state that is updated at each time step (h_t = f(W x_t + U h_{t-1} + b)). This enables modeling dynamic processes and variable-length sequences. Modifications such as LSTM and GRU address the vanishing gradient problem. The conductor lowers the baton: the symphony is over. The recurrent network, remembering the entire context, writes the final word and falls silent.

History

The foundations trace back to the work of John Hopfield (1982) and networks with feedback. In 1986, David Rumelhart et al. applied backpropagation to RNNs. Practical application was limited by the vanishing/exploding gradient problem. In 1997, Sepp Hochreiter and Jürgen Schmidhuber proposed LSTM (long short-term memory) with gated units—valves—solving long-term dependency issues. In 2014, Kyunghyun Cho et al. introduced GRU. Since the mid-2010s, RNNs have been gradually replaced by transformers but remain important in streaming tasks.

How it works

At step t, the RNN receives the input vector x_t and the previous hidden state h_{t-1}, computes the new state: h_t = \tanh(W_x x_t + W_h h_{t-1} + b). The vector h_t is fed to the output layer to predict y_t and passed to the next step. The parameters W_x, W_h, b are shared across all steps, enabling generalization to sequences of different lengths. Training is done by unfolding the network in time (backpropagation through time). LSTM adds a memory cell c_t and three gates: forget, input, and output, which regulate the flow of information.

h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)
h_t — hidden state at step t; x_t — input vector; W_{xh} — input weight matrix; W_{hh} — recurrent weight matrix; h_{t-1} — previous state; b_h — bias; tanh — hyperbolic tangent

Open problems & fun facts

Vanishing/exploding gradient problem; Difficulty capturing long-term dependencies (partially solved by LSTM); Sequential processing hindering parallelization; Difficulty training for very long sequences; Sensitivity to rare words in text processing

💡 In 2016, an LSTM-based RNN learned to generate text passages so similar to Tolstoy's style that literary scholars could not distinguish them from the original in 40% of cases.
