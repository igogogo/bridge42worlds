evidential neural networks

3

A neural network that, instead of a single answer, reports how confident it is in it — like a weather forecast with a 70% chance of rain.

In practice: Safe medical diagnosis: in addition to detecting a tumor, the network indicates the confidence level, warning the doctor if the prediction is unreliable.
Evidential neural networks output Dirichlet distribution parameters for classification, representing belief masses. The model learns to provide high evidence for the correct class by minimizing a loss function consisting of expected mean squared error and Kullback–Leibler divergence, which penalizes evidence for other classes. This allows quantifying epistemic (model) and aleatoric (data noise) uncertainty and detecting anomalies.

History

Dempster–Shafer theory was developed by Arthur Dempster in the 1960s and Glenn Shafer in the 1970s. Evidential neural networks emerged in the 1990s but gained popularity in the 2010s due to attention to AI reliability. Variants like Deep Evidential Regression (Sensoy et al., 2018) brought them into the mainstream.

How it works

Instead of probabilities that sum to one, the network provides evidence for each class. Imagine giving points to candidates: the more evidence, the more points. If the total sum is small, the network admits ignorance. Training penalizes evidence for incorrect classes and encourages evidence for correct ones, and regularization prevents the network from being overconfident without justification.

💡 If an evidential network is shown a completely new type of image, it will honestly indicate high uncertainty, unlike a regular network that might confidently make a mistake.
A regular neural network (a trainable computer system) gives a single definite answer. An evidential network provides a spectrum of possibilities with evidence weights — like a jury where each opinion is weighted. It uses Dempster–Shafer theory (a mathematical framework for reasoning under incomplete data) and tells not only the answer but also the degree of ignorance: when data is insufficient, it honestly admits 'I don't know'.

Evidential neural networks combine Dempster–Shafer evidence theory with deep learning. For classification, the network predicts parameters of the Dirichlet distribution, which is conjugate to the categorical distribution. The sum of evidence S = ∑ α_k, where α_k = e_k + a_k, e_k is the evidence for class k, a_k is a prior value (usually 1). Belief in class k: b_k = e_k / S. Loss function: L = ∑ (y_j – p_j)² + λ_t ∑ p_j log(p_j / α_j), where p_j = α_j / S. This encourages high evidence for the correct class and penalizes conflicting evidence.

History

Dempster (1967) and Shafer (1976) introduced belief functions. Denoeux (1995) proposed neural network models based on them. In 2018, Sensoy, Kaplan, and Kandemir extended the approach to deep learning with the Dirichlet distribution. Recent work addresses calibration, adversarial robustness, and applications in medicine and autonomous driving.

How it works

The output layer gives K nonnegative values e_k. Dirichlet concentrations α_k = e_k + a_k. Loss function: L_i(Θ) = ∫ ||y_i – p||² (1/B(α_i)) ∏ p_j^{α_{ij}-1} dp + λ_t D_KL( Dir(p; ilde{α}_i) || Dir(p; 1) ), where ilde{α}_i = y_i + (1 – y_i) ⊙ α_i. This is equivalent to minimizing expected loss and penalizing non-uniform Dirichlet for incorrect classes. Uncertainty is measured by Dirichlet entropy or the sum of evidence.

\operatorname{Dir}(\mathbf{p} | \boldsymbol{\alpha}) = \frac{\Gamma(\sum \alpha_k)}{\prod \Gamma(\alpha_k)} \prod p_k^{\alpha_k - 1}
p is the vector of class probabilities, α_k are concentration parameters (>0) obtained from the network output, Γ is the gamma function

Open problems & fun facts

Calibration of predicted uncertainties; Computational costs for sampling or integration; Sensitivity to out-of-distribution data remains an open question; Interpretability of evidential output
