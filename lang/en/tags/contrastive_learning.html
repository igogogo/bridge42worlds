Contrastive Learning

7

Training by comparing similar and dissimilar — that's how contrastive learning works. Instead of memorizing labels, a neural network learns to capture the essence, distinguishing a cat from a dog even if they weren't named.

In practice: Face recognition without labels, searching for similar photos in large archives, improving diagnoses from medical images when labeled data is scarce.
Contrastive learning is an approach in machine learning that allows building high-quality data representations without labels (self-supervised learning). It relies on the concept of contrastive loss: the model attracts representations (embeddings) of semantically close objects (positive pairs) and repels representations of unrelated ones (negative pairs). For example, in images, positive pairs are different views (augmentations) of the same photo, while negatives are all other images in the mini-batch. This way, the neural network learns to extract invariant features, ignoring irrelevant variations in lighting, rotation, scale. The method underpins many modern recognition systems, where it often outperforms supervised learning when labels are scarce.

History

The idea of learning by comparisons is old: back in 2006, 'Siamese networks' were used for signature verification. But the modern boom began in 2018–2020 when researchers from Google (SimCLR) and Facebook (MoCo) proposed ways to train large neural networks without human supervision by creating pairs from a single image with different distortions.

How it works

Take one image and create two new versions — for example, rotate it and change its color. These two versions form a positive pair. Other images in the set serve as negative examples. The neural network converts each image into a vector of numbers. Its task is to reduce the distance between the vectors of the positive pair and increase it for negative pairs. Over time, the vectors start to encode the meaning of the image rather than random details.

💡 OpenAI's CLIP system, trained contrastively on image-text pairs, can generate images from descriptions even though it was never directly taught artistic style — it simply captured the correlations.
Contrastive learning is a method where a computer program (neural network) is trained to find similarities and differences between objects. It is shown pairs of examples: some pairs are alike (e.g., two photos of the same person), others are different (photos of different people). The program tries to make similar objects end up close together in its 'memory' (feature vector) and dissimilar ones far apart. It's like a 'find the pair' game, but for millions of images.

Contrastive learning is a family of representation learning methods in which the model optimizes a metric space so that semantically similar objects map to nearby points, and dissimilar ones to distant points. Formally, for each anchor example x, a positive example x⁺ is formed, typically via augmentations or context, along with a set of negative examples {x⁻_i}. A loss based on softmax comparison is minimized: the model incentivizes high similarity between x and x⁺ relative to all other pairs. A key innovation in recent years is the use of large mini-batches and memory mechanisms to store negative examples (MoCo) or the elimination of negative pairs via asymmetric architectures (BYOL, SimSiam). Theoretical analysis connects contrastive learning to maximizing mutual information and learning on positive-definite kernels.

History

The roots trace back to metric learning: Siamese networks (Bromley et al., 1993) for signature comparison. In 2006, Hadsell and LeCun proposed contrastive loss for learning invariant representations. Revival of interest is linked to progress in self-supervised learning for images: in 2018, the InstDisc model (Wu et al.) used a memory bank; breakthroughs came with MoCo (He et al., 2020) with a queue of negative examples and SimCLR (Chen et al., 2020) with large batch sizes and strong augmentation. These works showed that contrastive pretraining achieves accuracy close to supervised learning, and sometimes surpasses it when fine-tuning on small datasets. The approach was later adapted for video, audio, graphs, and multimodal data (CLIP, 2021).

How it works

The algorithm includes three stages: (1) stochastic data augmentation creates two independent representations of the same input (e.g., random cropping, color distortion); (2) an encoder (ResNet, ViT) maps them into vectors in a latent space; (3) a projection head (MLP) transforms them into a lower-dimensional space where the contrastive InfoNCE loss is computed: L = -log[ exp(sim(z_i, z_j)/τ) / ∑_{k=1}^{2N} 1_{k≠i} exp(sim(z_i, z_k)/τ) ], where sim is cosine similarity, τ is a temperature parameter. Optimization reduces the cross-entropy between the distributions of positive and negative pairs. To prevent representational collapse (all vectors degenerating to a single point), mechanisms are employed: negative pairs from a queue (MoCo), stop-gradient and predictor (BYOL), clustering (SwAV). As a result, the latent space acquires semantic structure invariant to the specified transformations.

L_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k=1}^{2N} \mathbf{1}_{k \neq i} \exp(\text{sim}(z_i, z_k) / \tau)}
L_{i,j} — loss value for the pair (i, j); z_i, z_j, z_k — representation vectors (embeddings) in the latent space (dimensionless, normalized); sim — similarity function, typically cosine similarity: sim(z_i, z_j) = z_i^T z_j / (||z_i|| ||z_j||) (dimensionless, from -1 to 1); τ — temperature parameter (positive number, usually 0.1–0.5), controls the sharpness of the distribution; N — mini-batch size (number of original images, after augmentation we get 2N vectors); 1_{k ≠ i} — indicator function, excluding the pair i=j from the denominator

Open problems & fun facts

How to choose augmentations that guarantee semantic preservation for arbitrary data types (audio, graphs, video)?; Why some methods (BYOL, SimSiam) work without negative pairs, avoiding collapse — there is no complete theoretical clarity.; Can contrastive learning be extended to continuous output tasks (regression) or time series without quality loss?; Does a universal contrastive pretraining exist that transfers to any downstream task without fine-tuning?
