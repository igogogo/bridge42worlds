Turing machine

An imaginary mechanism with an infinite tape and a head that reads and writes symbols, following a simple list of rules. This is the embodiment of the very idea of an algorithm.

In practice: Any computer program — from a calculator to an AI assistant — reduces to instructions that a Turing machine can execute. The entire theory of computation is based on it.
Formally, a Turing machine consists of an infinite tape divided into cells, each containing a symbol from a finite alphabet; a control unit with finite state memory; and a head capable of reading, writing, and shifting by one cell. The transition function determines, based on the current state and the read symbol, a new symbol, the direction of head movement (L/R), and a new state. The machine starts with an input word on the tape and may halt in an accepting or rejecting state, or get stuck in an infinite loop. A universal Turing machine can simulate any other machine given its description — anticipating the concept of a programmable computer.

History

Alan Turing devised this model in 1936 while tackling the decidability problem of mathematical statements. His abstract 'machine' became the definition of what it means to 'compute'.

How it works

The machine works in steps, like a metronome. On each tick: reads a symbol — finds the corresponding row in the rule table — executes the instruction — moves to the next tick. If it enters a special 'accept' or 'reject' state, it halts. The tape content after halting is the result. In this way, one can add numbers, find a path in a maze, or play chess.

💡 The simplest universal Turing machine, devised by Marvin Minsky, uses only 7 states and 4 symbols — and yet it can compute everything a powerful supercomputer can, albeit incredibly slowly.
A Turing machine is a recipe written on an infinitely long tape divided into cells. The cells contain letters of an alphabet, and the machine's 'head' looks at one cell. Depending on what it sees and its 'internal state' (like a mood), it replaces the letter, shifts one cell left or right, and transitions to another state. It starts with input data and runs until it reaches a 'stop' command. Remarkably, this is enough to reproduce any conceivable computing process.

However, adding a stack (pushdown store) makes the machine equivalent to a counter automaton — and this is strictly weaker than a Turing machine (pushdown automata recognize context-free languages).
A deterministic Turing machine (DTM) is a 7-tuple (Q, Σ, Γ, δ, q0, q_accept, q_reject), where Q is a finite set of states; Σ ⊂ Γ \ {⊔} is the input alphabet; Γ is the tape alphabet (includes blank ⊔); δ: (Q \ {q_accept, q_reject}) × Γ → Q × Γ × {L, R} is a partial transition function; q0 ∈ Q is the initial state; q_accept, q_reject ∈ Q are terminal states. A configuration includes the state, tape contents, and head position. A single transition step: δ(q,a) = (q',a',d) changes the state to q', writes a', moves the head by d. The machine accepts a word if the trajectory leads to q_accept. The language recognized by a DTM is recursively enumerable (if infinite loops are possible) or decidable (if it always halts). A non-deterministic machine (NTM) has a multivalued δ, and accepts if there exists a path to q_accept. Complexity classes P and NP are defined via time constraints on DTM and NTM, respectively.

History

In 1936, Alan Turing, solving David Hilbert's Entscheidungsproblem (decision problem), introduced the notion of an 'a-machine' (automatic machine) in his paper 'On Computable Numbers'. His goal was to formalize the intuitive concept of an algorithm. Independently, Alonzo Church arrived at an equivalent notion via λ-calculus. The Church-Turing thesis asserts that any intuitively computable process can be implemented on a Turing machine. In 1945, John von Neumann used this model in the EDVAC architecture — the prototype of modern computers. In 1985, David Deutsch proposed a quantum Turing machine, paving the way for quantum computing.

How it works

A Turing machine computes by manipulating symbol strings. Algorithmically, it is equivalent to a programming language with a single array of infinite length. Key properties: existence of a universal machine (interpreter), undecidability of the halting problem (one cannot algorithmically determine whether an arbitrary machine halts on a given input), the recursion theorem (a machine can obtain its own description). In complexity theory, one considers oracle machines (with extra information) and probabilistic machines (with a random bit source). Quantum Turing machines operate on states in a Hilbert space and use unitary transformations; they do not violate the Church-Turing thesis but may provide exponential speedup for certain problems.

\delta(q, a) = (q', a', d), \quad d \in \{L, R\}
q — current state, a — symbol read from the tape, q' — new state, a' — symbol to write, d — head shift direction (L — left, R — right)

Open problems & fun facts

P vs NP problem: Does there exist a polynomial-time algorithm for problems whose solutions can be verified in polynomial time on a deterministic Turing machine?; Characterization of physical systems capable of realizing hypercomputation (exceeding the power of a Turing machine); Lower bounds on complexity for specific problems: prove that matrix multiplication requires Ω(n² log n) time on a Turing machine (or refute it)
