# ТЗ: связать учебные курсы с остальным сайтом + перевод

**Дата:** 2026-07-25 · Для специалиста по обучающим материалам

## Контекст

Курс физики уже собран: 14 тем × (обзор + 3 параграфа) + обзорные лекции, интерактивные модели,
страницы `course.html`, `learn.html`, `lecture.html`, `memo.html`, `frontier.html`, лаборатории `lab-*.html`,
данные в `data/theory/courses/**`.

Сейчас курс живёт **отдельно** от основного сайта. Нужно ввести его в общий периметр.

## Задача 1. Связать материалы курса с контентом сайта

У нас есть три связующих слоя, к которым можно и нужно цепляться:

- **Теги** — понятия (`electric_field`, `entropy`, `ion_channel`, …), у каждого своя страница
  `/lang/{lang}/tags/{tag}.html` со списком статей по теме.
- **Законы** — реестр формул и принципов, страницы `/lang/{lang}/laws/{law}.html`.
- **Учёные** — страницы `/lang/{lang}/scientists/{id}.html`.
- **Статьи** — 1900+ разборов свежих научных работ (arXiv), у каждой 4 уровня сложности.

**Что сделать:** в JSON каждого урока (`data/theory/courses/<тема>/<номер>-<слаг>.json`) добавить поля
привязки, например:

```json
"tags": ["electric_field", "coulomb_law"],
"laws": ["coulombs_law"],
"scientists": ["Charles-Augustin de Coulomb"]
```

Идентификаторы брать из наших справочников:
- теги — `lang/ru/data/tags-list.json` (поле `en` — это id)
- законы — `lang/ru/data/laws-list.json`
- учёные — `lang/ru/data/scientists.json`

Если нужного понятия в справочниках нет — **не выдумывать id**, а прислать список недостающих:
мы дорастим справочники (у нас есть механизм роста).

**Зачем:** тогда под каждым параграфом курса можно автоматически показывать «Свежие работы по теме»
(реальные статьи из архива) и ссылки на страницы закона/учёного — учебник перестанет быть замкнутым
и свяжется с живой наукой. Обратная связка тоже: со страницы тега можно вести в урок курса.

## Задача 2. Перевод курса на 4 языка

Сейчас материалы курса на русском (поле `ru` в JSON). Сайт работает на **ru / en / es / ar**
(арабский — с раскладкой справа налево).

**Что сделать:** структуру JSON подготовить под мультиязычность по образцу остального сайта —
рядом с `ru` появляются `en`, `es`, `ar` с той же схемой полей (`title`, `subtitle`, `intro`,
`formula`, `derivation`, `example`, `synthesis`, `curiosities`, `appendix` …).

Перевод мы можем прогнать нашим движком (он уже переводит статьи и справочники) — от вас нужно:
1. подтвердить финальность русских текстов (переводить черновики дорого),
2. отметить, что **переводить нельзя** (обозначения величин, названия констант, формулы),
3. проверить пару готовых переводов на терминологию.

## Задача 3. Включение в общий периметр сайта

Чтобы курс не выглядел «сбоку», нужно:
- единая шапка/меню и брендовый стиль (как на остальных страницах),
- пункт в навигации,
- работающий переключатель языков,
- страницы курса в карте сайта (sitemap) и в поиске.

Техническую часть сделаем мы — от вас нужен список страниц курса, которые должны быть
публичными, и их названия на 4 языках.

## Ограничения

- Аудитория — взрослая, неподготовленная; тон как на сайте (научпоп, без снисходительности).
- **Без алкогольных аналогий** (просьба владельца, арабская аудитория).
- Формулы и константы — с указанием единиц; у формул желательно указывать автора.
- Тексты должны хорошо переводиться: без каламбуров, завязанных на русский язык.

## Приложение: конкретика по справочникам и подбору статей
*(дополнено 2026-07-25 — курс ещё в работе, это ориентир на будущие материалы тоже)*

### Откуда брать идентификаторы (наши справочники)

| Что | Файл | Что брать |
|---|---|---|
| **Теги** (понятия) | `lang/ru/data/tags-list.json` | поле `en` — это id (`electric_field`), `ru` — название для людей, `domain` — область |
| Описания тегов | `lang/ru/data/tags.json` | текст описания — полезно свериться, о том ли понятии речь |
| **Законы** | `lang/ru/data/laws-list.json` | id закона + `name`, `type`, связанные теги |
| **Учёные** | `lang/ru/data/scientists.json` | id (имя латиницей), поля `fields`, `related_tags` |
| **Разделы arXiv** | `data/arxiv-categories-ru.json` | код раздела → название (156 разделов, 4 языка) |
| Связи между всем | `data/knowledge-graph.json` | готовый граф тег⇄закон⇄учёный — видно, что с чем уже связано |

**Правило:** id пишем ровно как в справочнике, не придумываем. Чего нет — присылайте списком,
мы дорастим справочники (механизм роста уже работает: `run.py tags --gaps N --focus "тема"`).

### Как подобрать статьи для урока (через поиск на сайте)

1. Откройте страницу тега: `bridge42worlds.academy/lang/ru/tags/<id>.html` — там уже собраны все
   наши статьи по этому понятию, отсортированные по дате.
2. Либо общий поиск на главной: он ищет по названиям, темам, авторам и учёным
   (`#тег`, `@автор`, `!учёный` — префиксы для точного поиска).
3. Отберите **2–4 статьи на параграф**: не самые сложные, а те, где видно, как понятие из урока
   работает в живом исследовании.

### Как вставлять статьи в учебный материал

Лучше всего — **как пример из сегодняшней науки** в конце параграфа: короткая подводка своими
словами + ссылка. Например:

> «Тот же закон Кулона сегодня работает в расчётах белковых молекул — вот свежая работа:
> *[название статьи]*».

Технически удобнее всего добавить в JSON урока список:

```json
"examples_from_articles": [
  {"id": "2607.11122", "why": "здесь закон Кулона используется для расчёта белка"}
]
```

Мы сами подставим корректную ссылку, обложку и заголовок на нужном языке — вам достаточно указать
**id статьи** (виден в адресе: `/archive/2026-07-13/2607.11122/`) и **одну фразу, чем она полезна уроку**.

### Что это даёт

- Учебник перестаёт быть замкнутым: от формулы можно перейти к реальной работе этого года.
- Обратная связка: со страницы тега/закона появится ссылка «изучить тему с нуля» → в урок курса.
- Курс попадает в общий поиск и карту проекта.

### Про незаконченные материалы

Курс ещё пишется — привязку тегов и подбор статей достаточно делать **для готовых** тем,
остальные по мере готовности. Перевод тоже запускаем только по финальным русским текстам.
