# Здесь промптов больше нет

Рабочие промпты живут в **`data/prompts/`** — именно оттуда их читает генератор
(`common.load_prompt`). Здесь лежала копия от 25 июля 2026, снятая для разбора
контент-менеджером; она отстала на месяц и не влияла ни на одну статью.

Копию удалили 4 августа 2026 по одной причине: архитектор правил её, отчитался
о работе — и работа не применилась, потому что генератор её не читает. Ловушка
стоила ложного отчёта владельцу.

Если нужно посмотреть, как промпты выглядели в июле: `git log -- content-manager/prompts/`.

Разбор уровней и рекомендации, ради которых копия и снималась, остались рядом:
[ТЗ-уровни-текста.md](../ТЗ-уровни-текста.md), [АНАЛИЗ-и-РЕКОМЕНДАЦИИ.md](../АНАЛИЗ-и-РЕКОМЕНДАЦИИ.md),
[ТЗ-РЕАЛИЗАЦИЯ.md](../ТЗ-РЕАЛИЗАЦИЯ.md).
