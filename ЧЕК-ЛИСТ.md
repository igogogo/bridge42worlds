# Чек-лист перед публикацией

Заведён 2026-07-28 после дня, в котором несколько ошибок дошли до живого сайта. Все они были
одного типа: проверка смотрела на **артефакты** (файлы на месте? переводы есть? ссылки целы?),
а не проходила **путь читателя**. Поэтому список построен по путям.

Часть проверок автоматизирована: `python audit_site.py` (см. раздел «Что делает машина»).
Машина ловит то, что можно сосчитать; глаза нужны для того, что можно только увидеть.

---

## Как пользоваться

Перед каждой публикацией: сначала `python audit_site.py`, потом руками пройти четыре пути
из раздела «Пути читателя» — по одному на каждый тип страницы. Занимает минут десять.

**Правило кэша.** Если правка «не применилась» — сначала жёсткое обновление (Ctrl+F5).
Браузер держит стили и скрипты, и половина ложных тревог именно отсюда.

## Пути читателя — проходить руками

### Путь 1. Читатель выбрал английский

1. Открыть `/lang/en/index.html`
2. **Строка языков видна** и в ней четыре языка, EN подсвечен
3. Нажать на статью → **открылась английская статья**, не русская
4. Вернуться назад → язык всё ещё английский
5. Перейти на тег из карточки → страница тега **английская**
6. Открыть учебный раздел `/learn.html` → язык сохранился

> Здесь ломалось дважды: строка языков была пустой (не публиковался `config.json`),
> и карточки вели в язык по умолчанию вместо языка страницы.

### Путь 2. Читатель выбирает глубину

1. В ленте у карточки **три кнопки**: Просто · Популярно · Подробно
2. Нажать «Подробно» → открылась подробная версия
3. Вернуться в ленту → «Подробно» подсвечено, заголовки ведут в подробную
4. Перейти на тег → уровень сохранился, подсвечен
5. На карточке тега сменить уровень → **сменился текст карточки И список статей под ней**
6. Внутри статьи — **четыре** кнопки (с «мини»), ряд прилипает к верху при прокрутке
7. Открыть `mini.html` напрямую → подсвечена «Мини»

> Мини есть только на странице статьи — это отдельный файл. В лентах его нет намеренно:
> там он был режимом показа и молча превращался в «популярно».

### Путь 3. Читатель на телефоне

Ширина 375. Проверять именно в портретной ориентации.

1. Меню-гамбургер открывается **в пределах экрана**
2. **Список тегов у статьи виден** (не исчезает и не требует поворота экрана)
3. Кнопки — не меньше 40 пикселей по высоте, попасть пальцем легко
4. Поиск: нажал — поле открылось, **видно куда вводить**, ввод работает
5. Карточки по ширине экрана, длинные ссылки переносятся
6. Реакции и комментарии не наезжают друг на друга
7. Ряд уровней на карточке не разваливается на две строки

### Путь 4. Арабский читатель

1. `/lang/ar/index.html` — страница **справа налево**
2. Элементы не наезжают, ничего не уходит за край
3. Стрелки и указатели зеркальны (← вместо →)
4. Учебный раздел на арабском: `/learn.html?lang=ar`

## Внешний вид — смотреть глазами

- **Шапка не прыгает** между типами страниц: одинаковый набор и порядок элементов
- **Кнопки одной высоты** в правом кластере шапки
- Переключатель уровня **не в шапке** — он управляет текстом карточки и стоит рядом с ним
- Иконки **с подписями** там, где смысл неочевиден; голая иконка только там, где контекст ясен
- Нет эмодзи — только наш штриховой набор (эмодзи рисуются по-разному в каждой системе)
- Ничего не «схлопнулось» в сплошной текст — верный признак, что для блока забыли стиль

## Что делает машина

`python audit_site.py` проверяет:

| Что | Почему это важно |
|---|---|
| Все страницы раздела на месте | простая полнота |
| Переводы уроков и справочников на 4 языка | иначе читатель видит пустоту |
| Битые внутренние ссылки | ловит переносы и переименования |
| Кириллица в нерусских версиях | главный признак утечки языка |
| Русские заголовки в индексах лент | то же, но в данных |
| **`config.json` в списке публикации** | без него нет строки языков на всём сайте |
| **Картинки параграфов курса в публикации** | правило исключения jpg однажды вырезало их целиком |
| **Карта сайта не зовёт на несуществующее** | мягкие 404 портят индексацию |
| **Карточки ведут в язык своей страницы** | иначе выбор языка теряется на первом клике |
| Мусор в корне (страницы без единой ссылки) | старые прототипы утекали на сайт |
| Сорванные записи при сборке | одна запись не должна ронять час работы |

## Грабли, на которые уже наступали

**`.gitignore` не убирает то, что уже отслеживается** — нужен `git rm --cached`.
Так в репозиторий попали лишние 7 гигабайт, и GitHub Pages перестал публиковать сайт.

**Правило, продублированное в двух местах, разойдётся.** Список публикации в
`cloudflare/deploy_r2.py` повторяет `.gitignore` вручную.

**Широкое правило исключения опаснее узкого.** «Не публиковать любой jpg» вырезало картинки
курса, у которых нет webp-двойника. Правильно: «не публиковать jpg под `lang/`».

**Ошибка, заглушённая пустым `catch`, молчит годами.** Строка языков была пустой на всём сайте,
и никто не видел причины — запрос к `config.json` падал в тишину.

**Сборка и публикация одновременно дают смесь версий.** Защита — файл `.build.lock`.

**Вставил блок — добавь стиль.** Блок-мост к курсу неделю выглядел сплошным текстом, потому что
разметку добавили, а CSS к ней — нет.
