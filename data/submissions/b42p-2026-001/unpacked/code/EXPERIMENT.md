# Описание эксперимента

## Установка

Диск (колесо) вращается в вертикальной плоскости в поле тяжести Земли. На диске
и рядом с ним закреплены 10 независимых сенсорных узлов на базе ESP32
(`agent_id` от 0 до 9):

- **2 статических узла** (`agent_id` 0, 1) — закреплены неподвижно, вне
  вращающейся части. Служат опорным/контрольным измерением: в состоянии покоя
  акселерометр должен показывать примерно 1g.
- **8 вращающихся узлов** (`agent_id` 2..9) — закреплены на ободе диска.
  Угловая скорость вращения подбирается так, что в верхней точке обода модуль
  ускорения близок к 0g, а в нижней — к 2g (см. теоретическую модель:
  ω = √(g/R), |a(t)| = 2g·|sin(ωt/2)|).

## Что измеряет узел

Каждый узел несёт трёхосевой акселерометр LIS3DSH. Показание `g` — это модуль
полного вектора: `g = sqrt(ax² + ay² + az²)`, а не отдельная ось.

Момент, когда снимается показание акселерометра, определяется не таймером с
фиксированной частотой, а побочным эффектом другого процесса: узел непрерывно
генерирует аппаратно-случайные 32-битные числа и проверяет их на простоту
(детерминированный тест: пробное деление + Миллер–Рабин). Когда очередное
число оказывается простым — это и есть момент измерения: в этот момент
считывается акселерометр и фиксируется реальное аппаратное время
(микросекунды с начала сессии). То есть проверка на простоту работает как
**случайный триггер измерения**, а не как способ узнать время — точное время
и так пишется отдельным полем на каждую запись.

Из-за этого моменты измерений распределены во времени неравномерно (в среднем
раз на ~22 проверки, что соответствует плотности простых чисел в районе
2³²), а не через равные интервалы.

## Поля данных

На каждую найденную простую (= каждое измерение) пишется одна запись:

| поле | смысл |
|---|---|
| `agent_id` | номер узла (0-9) |
| `prime` | найденное простое число |
| `g` | модуль ускорения в этот момент, g |
| `timestamp_us` | реальное время, мкс с начала текущей сессии узла |
| `checked_since` | сколько чисел проверено с прошлого найденного простого |

Отдельно, на уровне сессии (раз в цикл сбора), пишется сводная запись:
`agent_id`, время старта/длительность сессии, суммарные счётчики проверенных
чисел и найденных простых, статус синхронизации времени и датчика и т.п.

## Протокол сбора

Узел работает циклами: короткое окно сбора данных (несколько секунд —
настраивается с сервера), затем отправка накопленного буфера на сервер, затем
пауза до следующего цикла. То есть данные не собираются непрерывно — это
последовательность коротких плотных отрезков с паузами между ними.

## Что ищем

Для статических узлов (0,1) нулевая гипотеза — гауссов шум вокруг 1g.
Для вращающихся узлов (2-9) нулевая гипотеза — теоретическая кривая
|a(t)| = 2g·|sin(ωt/2)| (частота может быть подобрана не идеально точно).

В обоих случаях интересуют отклонения от соответствующей нулевой модели:
в спектре, в форме распределения, в согласованности между узлами — на разных
масштабах (один оборот / все обороты в пределах минуты / вся сессия целиком
для одного узла / корреляции между узлами).
