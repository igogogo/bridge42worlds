# Работы не из arXiv: приём

Владелец 11.09.2026: «у нас появился опыт инкапсулирования статей не из архива. Там было
много проблем, которые мы собирали руками, и это разные источники — они могут быть не PDF.
Давай такую попытку: ты сам ищешь в сети свежее и интересное».

Первая такая работа — `2609.90001`, разбор OpenAI о взрыве в уравнениях Навье–Стокса.
Она делалась целиком руками: пять языковых модулей, три уровня, сборщик, рисунки — сорок
тысяч строк на одну статью. Повторять это на каждую находку нельзя.

## Что изменилось

Разбор пишет **обычный конвейер**, как для любой работы с arXiv. Руками делается только
ПРИЁМ: найти первоисточник, снять метаданные, положить текст. Дальше `run.py ids <номер>`
и всё идёт своим чередом — уровни чтения, пять языков, разметка понятиями, вектор, карточки.

Так вышло потому, что у конвейера нашлась ровно одна дверь: `fetch_one_arxiv()` сперва
смотрит в нашу локальную базу метаданных и только потом идёт в сеть. Работа, положенная
в эту базу, для конвейера неотличима от любой другой — менять генератор не понадобилось.

## Как это работает

1. **Запись источника** — `tools/outside/works/<номер>.json`. Лежит в `tools/`, а не в
   `data/`: `data/` публикуется целиком, рабочим файлам там не место.
2. **Номер** — свой, из хвоста `YYMM.900NN`. Формат нужен генератору (из номера выводится
   месяц), а `900xx` на arXiv не бывает — по номеру сразу видно, что работа наша.
3. **Полный текст** — `fulltext.txt` в папке статьи. Если он есть, генератор берёт текст
   с диска и за PDF не идёт вовсе. Это и решает «источники могут быть не PDF»: HTML-страница,
   препринт, технический отчёт — что угодно, лишь бы текст удалось снять.
4. **Лицензия** — по адресу из записи, через `gen_arxiv.license_class()`. Класс `analysis`
   значит: пересказ наш, авторские рисунки и абстракт не показываем.

## Приём

Запись готовит тот, кто читал страницу источника — человек или агент. Разбирать чужую
вёрстку кодом не пробуем: издателей десятки, у каждого своя, и надёжнее прочитать глазами.

```bash
python tools/outside/intake.py заготовка.json          # проверить и показать, что будет
python tools/outside/intake.py заготовка.json --apply  # завести работу
python run.py ids 2609.90002                           # обычный разбор
```

Заготовка — обычный JSON:

```json
{
  "title": "Название работы как у источника",
  "authors": ["Фамилия И.", "..."],
  "date": "2026-08-20",
  "abstract": "Аннотация ДОСЛОВНО со страницы источника",
  "url": "https://...",
  "pdf": "https://...",
  "doi": "10.1038/...",
  "org": "Nature Aging",
  "licence_url": "https://creativecommons.org/licenses/by/4.0/",
  "categories": ["q-bio.CB", "q-bio.MN"],
  "fulltext": "необязательно: текст работы, если снят со страницы"
}
```

Обязательны: `title`, `date`, `abstract`, `url`, `licence_url`, `categories`.
`pdf` — если дан, текст снимается с него; иначе берётся `fulltext`; иначе остаётся одна
аннотация, и приём об этом честно предупреждает.

## Чего тут нет

Сборщика «своей работы» с рисунками и блоком машины знаний — это отдельная история, она
живёт в `tools/ownworks/` и нужна, когда разбор пишется руками. Здесь работа проходит как
обычная: наш пересказ по её тексту.
