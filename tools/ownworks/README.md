# Наши работы не из arXiv

Здесь лежат исходники разборов, написанных руками, для работ, которых на arXiv нет.
Папка на работу, внутри: тексты по языкам (`ns_<lang>.py`), сборщик `ns_build.py`
(собирает `lang/ru/archive/<дата>/<номер>/data.json`), рисунок `fig_build.py`,
последовательность выкладки `ns_publish.py`.

Номера — свои, из хвоста `YYMM.900NN`: формат нужен генератору (месяц выводится из номера),
а `900xx` на arXiv не бывает, по номеру сразу видно, что работа наша.

- `2609.90001` — OpenAI, «Finite Time Blowup for Navier–Stokes» (08.09.2026). Первая.
