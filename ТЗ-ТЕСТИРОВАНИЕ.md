## Как запустить у себя

```bash
python -m http.server 8420
```

Открыть `http://localhost:8420/lang/ru/index.html`. Ничего собирать не надо: сайт уже собран,
лежит готовыми страницами. **Не запускайте `run.py html` и `cloudflare/deploy_r2.py`** — это
часовая пересборка и публикация, их делает ведущий.

Важно: браузер держит стили и скрипты в кэше. Если правка «не применилась» — сначала жёсткое
обновление (Ctrl+F5), и только потом заводите находку.

## 1. Уровни чтения — главное, что переделано

У каждой статьи четыре глубины: **Просто**, **Популярно**, **Подробно** и **Мини** (совсем
короткая). Раньше их переключал бегунок в шапке, теперь — ряд кнопок с иконками. Бегунка не
должно остаться нигде.

**Как должно работать:**

| Где | Что видим |
|---|---|
| Лента (главная) | над названием каждой карточки три кнопки: Просто · Популярно · Подробно |
| Страницы тега, закона, учёного, раздела | те же три кнопки на карточках статей **и** отдельный ряд у самой карточки тега/закона — он переключает её текст |
| Страница статьи | один ряд из четырёх кнопок вверху (с Мини) и сжатый дубль внизу |

**Что проверить:**

1. Нажать «Подробно» на карточке в ленте → открывается подробная версия статьи, а не популярная.
2. Вернуться назад в ленту → «Подробно» подсвечено, названия статей ведут в подробную версию.
3. Перейти на страницу тега → выбор сохранился, подсвечено «Подробно».
4. На странице тега нажать «Просто» → меняется текст самой карточки тега **и** список статей под ней.
5. Внутри статьи ряд кнопок должен прилипать к верху при прокрутке.
6. Мини есть только на странице статьи. В лентах его быть не должно — это осознанно.
7. Открыть `mini.html` напрямую → активной подсвечена именно «Мини».

**Признак ошибки:** нажали уровень, а изменений нет; или подсвечен один уровень, а открыт другой.

## 2. Языки

Четыре языка: `ru`, `en`, `es`, `ar`. Арабский — справа налево.

1. На любой странице переключить язык — раскладка не должна ломаться.
2. **Кириллица в нерусских версиях — всегда ошибка.** Смотреть внимательно: подписи кнопок,
   заголовки блоков, единицы измерения, подписи на схемах.
3. В арабской версии проверить, что элементы не наезжают друг на друга и не уходят за край.
4. Учебный раздел: `/learn.html?lang=ar`, `/discoveries.html?lang=es`, `/reference.html?lang=en`,
   `/mathkit.html`, `/hypotheses.html` — на всех четырёх языках.

## 3. Учебный раздел

- `/learn.html` — дерево знаний, 14 тем. Внизу блок «Справочные материалы» и «Обзорные лекции».
- `/course.html?t=thermodynamics` — обзор темы, три параграфа.
- Открыть параграф: должен быть интерактивный стенд с ползунками, переключение единиц
  (СИ, бытовая, техническая, имперская, планковская), график, разбор формулы.
- **Испытание** под стендом: нажать «Дать задание» → появляется цель в величинах модели.
  Крутить ползунки → полоса приближения растёт, при попадании засчитывается.
- `/memo.html?t=thermodynamics&p=01-molecules` — шпаргалка со схемой, печать (Ctrl+P) не должна
  разрывать блоки посередине.
- Пройти проверку знаний до конца → начисляются звёзды, и они видны в оглавлении курса.
  Прогресс хранится в браузере, при очистке данных сбрасывается — это нормально.

## 4. Аналитика

`/lang/ru/analytics/` — десять представлений, переключаются вкладками.

1. **Дерево знаний** должно ветвиться: ствол → тема → год → статьи. Не веер из одной точки.
2. **Ритм** (спектр): есть сетка, подписи осей, пики подсвечены кружком с пунктиром к оси.
3. **Напряжение**: связи выровнены по колонкам, имена не разъезжаются.
4. **Панель вида** справа сверху: вращение, приближение, отдаление, возврат. После
   перетаскивания мышью автовращение выключается — кнопкой должно включаться обратно.
5. Полёт: скорость колесом и ползунком, клик по звезде в прицеле открывает статью.

## 5. Мобильная версия

Проверять на телефоне или в режиме устройства (ширина 375).

1. Меню-гамбургер открывается **в пределах экрана**, не уезжает за край.
2. Кнопки достаточно крупные, чтобы попасть пальцем.
3. Карточки не выходят за ширину экрана, длинные ссылки переносятся.
4. Список языков на карточке — в строку, не столбиком.
5. Граф знаний на телефоне ограничен по числу узлов, но ограничение снимается кнопкой.

## 6. Связность

1. Битые ссылки: `python run.py links` — эту команду запускать можно, она только читает.
2. С карточки тега перейти к статье и обратно.
3. Граф знаний: чекбоксы фильтров — при узком фильтре граф не должен становиться пустым.
4. Из раздела теории (`/lang/ru/theory/`) должен быть переход к учебному курсу — блок наверху.

## Как оформлять находку

Коротко и воспроизводимо:

```
Где:      /lang/ar/tags/entropy.html, телефон 375px
Что:      кнопки уровней наезжают на заголовок
Ожидал:   ряд кнопок над заголовком, не перекрывая его
Проверил: жёсткое обновление сделал, повторяется
```

Скриншот помогает. Если находка про язык — обязательно укажите, какой.
