# ТЗ: поиск по всему arXiv и воронка экспресс → полная

Решения владельца 2026-07-30, уточнены поздним вечером — схема ниже ОКОНЧАТЕЛЬНАЯ,
предыдущая версия с en-only «супер-экспрессом» для показа отменена.

## Воронка, три ступени

```
СТУПЕНЬ 0 — индекс (массово, дёшево):
  сырой EN-абстракт arXiv → вектор → единый индекс (2025–2026, ~400к, лицензионно чистые)
  · для ПОИСКА этого достаточно; никакой генерации заранее

СТУПЕНЬ 1 — экспресс (лениво, при первом попадании статьи в чью-то выдачу):
  абстракт → НАШ ОБЫЧНЫЙ ЭКСПРЕСС → на ВСЕХ языках сайта (штатный путь: генерация +
  переводы, дёшево flash-ем) → у статьи появляется настоящая страница-экспресс
  · карточка в выдаче — уже наша, на языке читателя, кликабельная
  · плашка «экспресс-версия · заказать полный разбор»

СТУПЕНЬ 2 — полная (по кнопке, на ЯЗЫКЕ ЗАПРОСА, только на нём):
  полный конвейер по PDF → advanced/popular/simple на языке заказавшего
  · остальные языки полной — следующими запросами, тем же механизмом
```

## Ключевое правило: ЭКСПРЕСС НЕ ПРОПАДАЕТ при апгрейде

Экспресс — не черновик, а слой, который остаётся жить:
- его короткий текст = mini полной статьи (не регенерим);
- его переводы на другие языки = аннотация/карточка выдачи там, где полной на этом
  языке ещё нет;
- у нас это «как-то так и сделано» (express_tiers, mini из экспресса) — ДОДУМАТЬ
  до конца: при on-demand генерации полной на языке X конвейер обязан переиспользовать
  уже оплаченные поля экспресса, а не генерить заново. Проверить и зашить в конвейер.

## UX выдачи

- Наша полная → карточка с обложкой, «читать разбор»;
- Наш экспресс → обычная карточка (уровень «экспресс» помечен как сейчас в ленте),
  внутри — плашка «заказать полный разбор ≈1 мин»;
- Ещё не тронутая arXiv-статья → карточка рождается В МОМЕНТ выдачи (ступень 1
  отрабатывает на топ-5 батчем, секунды) — читатель различий почти не видит;
- Весь топ внешний → строка «по этому запросу у нас пока нет разборов — закажите любой».

## Экономика ступеней (ленивый режим)

| Ступень | Когда | Цена |
|---|---|---|
| 0: вектор 400к | разово | ~$1–2 |
| 1: экспресс всех языков | первый показ статьи | ~$0.01–0.02/статья, только по увиденному |
| 2: полная на языке | по кнопке, потолок 10/день | ~$0.03–0.05 |

## Исполнители (круг 5)

ML+DevOps — ступень 0 и ленивый триггер ступени 1 в /api/search; ведущая — реюз
экспресса в конвейере полной (ступень 2); разработчик+дизайнер — карточки и плашки;
продукт — какие разделы arXiv в индекс первыми (его же расчёт долей).
