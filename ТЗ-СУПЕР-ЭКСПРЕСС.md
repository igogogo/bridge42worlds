# ТЗ: супер-экспресс — поиск по всему arXiv и воронка адаптации

Решения владельца 2026-07-30 (вечер). Адресаты: ML + DevOps (механика), разработчик +
дизайнер (UX), продукт (границы). Это сборка D в полном виде.

## Решения, зафиксированы

1. **Генерация по заказу — на языке запроса, только на нём.** Быстро и параллельно.
   Остальные языки той статьи — по следующим запросам (тот же механизм).
2. **Поиск ищет по ВСЕМУ arXiv** (лицензионно проходящему), стартовый охват 2025–2026,
   из нашей базы абстрактов. Вектор — по всем.
3. **Новый тир «супер-экспресс»**: адаптированный лёгкий пересказ абстракта, ТОЛЬКО
   английский, без картинок и уровней. Он живёт в поиске и в векторе. Отличается от
   нашего экспресса: не статья сайта, а поисковая сущность с кнопкой «адаптировать».

## Воронка целиком (пример: запрос на французском)

```
запрос fr → перевод en → вектор → ЕДИНЫЙ индекс (наши 2к + arXiv 2025-26 ~400к)
   → топ-5 (наши ранжируются выше при равном скоре — у нас есть разбор)
   → перевод карточек выдачи на fr на лету (уже работает, кэш KV)
       ├─ наша статья  → карточка с обложкой → читать разбор
       └─ супер-экспресс → карточка «arXiv · ещё не адаптировано»
                           → [Адаптировать за минуту] → очередь → конвейер
                              на ЯЗЫКЕ ЗАПРОСА → уведомление → полная статья
```

## Оптимизация к решению «адаптировать все абстракты заранее» — на выбор владельца

Массовая адаптация 400к абстрактов flash-ем ≈ $60–80 + время. НО для ПОИСКА адаптация
не нужна: вектор строится из сырого абстракта (он и так английский научный — это даже
каноничнее для матчинга с запросами).

**Предложение: ленивая адаптация.** В вектор — сырые абстракты (эмбеддинг 400к ≈ $1–2).
Супер-экспресс генерится в момент ПЕРВОГО попадания статьи в чью-то выдачу (flash,
батч на топ-5, ~секунда) и кэшируется навсегда. Итог тот же — «всё, что люди видят,
адаптировано», но платим только за реально увиденное: при 1000 поисков/день это
доллары в месяц вместо $60–80 разом. Массовый прогон остаётся опцией для топ-разделов.

## UX внешних карточек (дизайнер + разработчик)

- Бейдж-маркер «arXiv» + «ещё не адаптировано» на языке читателя;
- Без картинки — не пустая дыра, а плейсхолдер в брендстиле (наш дуотон, номер arXiv);
- Кнопка [Адаптировать] — заметная, с честным «≈1 минута»; после заказа — экран ожидания
  (факты/похожие наши статьи) → уведомление → редирект на готовую статью;
- Если топ-5 весь из внешних — сверху мягкая строка «в нашей библиотеке пока нет разбора
  по этому запросу — закажите любой»;
- Счётчик заказов/лимиты — уже в Worker.

## Границы (продукт)

- Лицензии: в индекс только разрешённое (аудит уже есть в bulk-select);
- Стартовый охват 2025–2026, расширение назад — по спросу;
- Потолки: заказ статьи 10/день (стоит), супер-экспресс ленивый — считать в норму поиска.
