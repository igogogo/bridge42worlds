# bridge42worlds

Научные статьи arXiv, пересказанные человеческим языком, на четырёх языках — русском,
английском, испанском и арабском. Плюс учебный раздел, справочники и карта связей между
понятиями. Сайт статический: Python собирает готовые страницы, Cloudflare их раздаёт.

Живой сайт: **bridge42worlds.academy**

## Начать работать

```bash
git clone <репозиторий>
cd bridge42worlds
python -m pip install -r requirements.txt
git switch -c имя-задачи
python -m http.server 8420
```

Дальше открываешь `http://localhost:8420` и правишь. Изменения в `js/` и `css/` видны
сразу по жёсткому обновлению — **пересобирать сайт для этого не нужно и нельзя**, почему
именно нельзя написано в правилах.

Работаешь параллельно с другими — заведи себе отдельную папку, чтобы не толкаться в одном
дереве:

```bash
git worktree add ../b42-моя-задача -b имя-задачи
```

## Что можно запускать всем

| Команда | Что делает |
|---|---|
| `python run.py stats` | сводка покрытия, ничего не меняет |
| `python run.py check` | проверка целостности данных |
| `python run.py links` | поиск битых ссылок |
| `python -m http.server 8420` | локальный просмотр |

**Чего не запускать никому, кроме ведущей сессии:** `python run.py html` (полная пересборка,
около часа) и `python split_push.py`. Причины — в правилах.

## Как устроено в двух абзацах

Раз в сутки скрипт забирает свежие статьи с arXiv, отбирает интересные, и языковая модель
пишет по каждой четыре версии разной глубины — от одного абзаца до разбора с формулами.
Затем всё переводится на три остальных языка, размечается тегами, привязывается к законам
физики и учёным, и генератор раскладывает это в готовые HTML-страницы.

Поверх статей — слой связей: теги, законы, учёные, разделы arXiv, граф знаний и аналитика.
Отдельно живёт учебный раздел: курс с интерактивными стендами, справочники формул и констант,
ретроспектива открытий.

Подробности — в [HANDOFF.md](HANDOFF.md).
