## DevOps — инфраструктура

Инструкция целиком: `cloudflare/DEVOPS-HANDOFF.md` (папка не в git, отдаётся файлом
`_devops-handoff.zip`).

**1. Выключить GitHub Pages.** Сейчас домен обслуживает Cloudflare, но Pages в настройках
репозитория всё ещё включён. Пока он жив, остаётся риск, что часть запросов уйдёт мимо Worker.
Проверить: `Settings → Pages → Source → None`.

**2. Убрать jpg из репозитория.** В git лежат 24 632 файла `.jpg` на 7,2 ГБ, на которые сайт
не ссылается — страницы давно используют `.webp`. Правило в `.gitignore` их не убирает, потому
что файлы уже отслеживаются:
```bash
git rm --cached -r --quiet "lang/**/*.jpg"
```
Локальные файлы при этом остаются на диске, история их помнит — восстановимы.

**3. Перестать хранить собранный сайт в git.** После переезда `lang/**` не нужен репозиторию:
страницы живут в R2. Это убирает 52 тысячи файлов из каждого коммита, ускоряет пуш с получаса
до секунд и снимает главную причину конфликтов между участниками.

**4. Вшить публикацию в пайплайн.** Сейчас `python cloudflare/deploy_r2.py --prune` запускается
руками после сборки. Сделать это последним шагом генерации вместо git-пуша.

**5. Включить тьютора.** Бот-помощник в курсе скрыт до переезда — `js/tutor.js` показывается
только на локальной машине и на `workers.dev`. После стабилизации выставить
`window.B42_TUTOR_ENABLED = true` и завести серверный ключ доступа (описано в
`cloudflare/TUTOR-LOCAL-TEST.md`).

**6. Сменить токен Cloudflare.** Он передавался в переписке при настройке — заменить на новый.

## Промпт-инженер — качество генерации

Всё, что определяет, каким выйдет текст статьи. Промпты в `data/prompts/`, единый блок стиля —
`data/prompts/_style-core.txt`.

**1. Проверить уровни на свежих статьях.** Четыре глубины должны отличаться не длиной, а
подходом: «просто» — без терминов, «популярно» — с метафорой, «подробно» — с формулами и
оговорками, «мини» — одна мысль. Взять десяток последних статей и посмотреть, держится ли
различие. Где сливается — править промпт, а не текст.

**2. Следить за словарём тегов.** Инструмент — `python tags_watch.py`: показывает статьи с
одним тегом или без, голодные домены и накопленные моделью предложения новых тегов. Словарь
закрытый: свободные теги подтягиваются к ближайшему из списка, поэтому пополнять его надо
осознанно, а не по каждому предложению.

**3. Переводы.** Проверка встроена (`validate_translation` в `gen_llm.py`): ловит кириллицу
в нерусском тексте, потерянные числа, изменённые формулы. Смотреть, что она отбраковывает —
это подсказка, где промпт перевода слабый.

**4. Не трогать без нужды** `refine` в конфиге: авто-полировка переписывала метафору так, что
она расходилась между уровнями. Выключена намеренно.

## Дизайнер — брендстиль и мобильная версия

Направление утверждено: охра → циан, шрифты serif и mono, карточки с тонкой линией и мягкой
тенью, плавные переходы. Набор иконок — свой, штриховой (`js/icons.js`, 25 штук).

**1. Довести иконки.** Остатки эмодзи по сайту заменить нашими. Причина не в эстетике: эмодзи
рисуются по-разному в каждой системе и ломают строгий вид, особенно на печати.

**2. Выровнять правый кластер шапки** — уровень, избранное, поиск, календарь, экспресс. Сейчас
элементы разной высоты и разъезжаются.

**3. Мобильная версия** — перенос реакций и комментариев, размер кнопок под палец, карточки
по ширине экрана. Отдельно проверить арабскую версию: она справа налево, и зеркалится не всё.

**4. Аналитика.** Взят подход инженерного дашборда: панель с мягкой двойной тенью, шапка с
пояснением справа, приглушённые сетка и подписи. Довести до конца по всем десяти
представлениям.

## Ведущая сессия — сборка и публикация

**1. Пересобрать сайт** после того, как участники закончат текущие правки. В сборку войдёт
накопленное за 28 июля и пока не опубликованное:

- уровни чтения кнопками вместо бегунка — в ленте, на карточках справочников, в статье;
- переключатель уровня на карточке тега, закона, учёного, раздела (был потерян вместе с бегунком);
- переключатель языков на четырёх новых страницах — ретроспектива, справочник, математика,
  гипотезы (материалы переведены, а сменить язык было нечем);
- дерево знаний в аналитике теперь ветвится: ствол → тема → год → статьи;
- график ритма — сетка, подписи осей, подсветка пиков;
- связи в «Напряжении» выровнены по колонкам;
- мини-панель вида в аналитике: вращение, приближение, возврат;
- поиск в шапке больше не раскрыт по умолчанию;
- мост из раздела теории к учебному курсу на всех языках.

**2. Залить в R2** — `python cloudflare/deploy_r2.py --prune`.

**3. Развести участников по рабочим деревьям.** Сейчас все сидят в одной папке, и ветка от этого
не спасает: ветка разделяет историю, а файлы общие. Отдельная папка на участника:
```bash
git worktree add ../b42-course course-work
```
