## 2. Ручка `/api/research`

**Вход** (POST, JSON):

```json
{ "question": "is the event still growing?", "lang": "en",
  "history": [{"q": "…", "a": "…"}], "turnstile": "<токен>" }
```

**Ответ:**

```json
{ "answer": "…текст с пометками [risk:peak_ahead] и [2608.27806]…",
  "summary_delta": "что этот ход добавил к пониманию",
  "panel": [{"id": "risk:peak_ahead", "kind": "risk", "title": "…",
             "hash": "#risk/peak_ahead", "anchor": "risk:peak_ahead",
             "score": 0.71, "cited": true}],
  "works": [{"id": "2608.27806", "title": "…", "url": "…", "date": "…",
             "score": 0.47, "cited": false, "no_text": false}],
  "concepts": [{"id": "warm_water_volume", "name": "warm water volume",
                "name_ru": "объём тёплой воды", "kind": "property"}],
  "kpis": [{"id": "kpi:n34_daily", "title": "Niño 3.4, daily", "hash": "#overview"}],
  "dayLeft": 57, "weekLeft": 243 }
```

**Проверка утверждений** — тот же адрес, другой режим:

```json
{ "mode": "verify", "lang": "en",
  "claims": ["The event has already peaked and is declining."] }
```

Ответ: `verdicts: [{n: 1, status: "supported|contradicted|unknown", why: "…"}]`.

**Особые ответы, которые надо показать читателю по-человечески:**

- `nothing_found: true` — вектор не нашёл ничего выше порога. Это правильный ответ, а не сбой;
- `unsupported: true` — модель ответила без единой годной пометки, и мы её ответ **не отдаём**.
  Отдаём найденное: пусть читатель сам решит. Это то же правило, что у `/api/ask`, и оно и
  отличает нас от болталки;
- `error: "captcha_failed"` — нужен токен Turnstile, как у бота;
- `error: "quota_day" / "quota_week"` — норма выбрана; в ответе `dayLeft` и `weekLeft`.

**Норма** — две дороги (сделано 08.09 по слову владельца):

- без токена — общая с `/api/ask`, по uid и адресу, с Turnstile;
- с токеном — заголовок `x-b42-token: <токен>` (или поле `token` в теле). Токен **заменяет
  капчу** и считается по своим лимитам; в ответе `dayLeft`/`weekLeft` — остатки токена.
  Ошибки: `token_required`, `token_invalid` (401), `token_expired` (403), `limit_day` /
  `limit_total` (429, в ответе `limit`).

Токен выдаю я: `POST /api/tutor/issue` с админ-ключом, поля `days` (до 60), `limitDay`
(по умолчанию 50), `limitTotal` (200), `note`. Скажите, сколько нужно на страницу — выдам.

## 2а. Сохранение исследований (D1, по uid)

Хранится на сервере под тем же uid, что и норма: вошедший — по аккаунту, иначе по сессии
(cookie). Чужие записи не видны и не перебираются. На читателя держим **50** последних.

```
POST /api/research/save   { "id"?: "…", "lang": "en", "title": "…", "summary": "…",
                            "turns": [{"q": "…", "a": "…", …}], "claims": ["…"] }
                          → { "ok": true, "id": "04d8904ecb4f4fcb", "updated": "…" }
                          без id — новая запись; с id — обновление своей (чужой → 404)
GET  /api/research/list   → { "items": [{ "id", "lang", "title", "summary", "created", "updated" }] }
GET  /api/research/list?id=…  → полная запись с turns и claims
POST /api/research/delete { "id": "…" } → { "ok": true, "deleted": 1 }
```

Пределы: до 40 ходов, до 40 утверждений, summary до 4000 знаков, title до 160. Ходы —
любой JSON, я его не разбираю: кладите то, что нужно вашей доске (панель, работы, понятия).
Проверено живьём 08.09: save → list → get → delete.

## 5. Что остаётся вам

Страница: доска слева, диалог справа. Формат ответа читается одной функцией — поля выше.
Что стоит держать в голове при отрисовке:

- **`cited` важнее `score`**: показывайте сначала то, что модель действительно процитировала,
  остальное — «рядом нашлось»;
- **`hash` ведёт на панель**, `url` — на нашу статью. Не путайте: первое остаётся внутри
  панели, второе уводит на сайт (тогда новой вкладкой);
- **`concepts` и `kpis` уже отфильтрованы** по процитированному — их можно рисовать облаком
  и плитками без своей логики;
- **`summary_delta`** — одна строка, её место в накопительном резюме исследования;
- **`unsupported` и `nothing_found` — не ошибки**, а содержательные ответы. Их надо показать,
  а не прятать за «что-то пошло не так».
